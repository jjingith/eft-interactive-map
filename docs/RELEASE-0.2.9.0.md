# 《逃离塔科夫》互动地图 · 0.2.9.0

永久免费，Windows 平台。

## 本次更新

### 新增「更新」页

顶部多了第 7 个视图「更新」：左边是游戏版本的更新时间线，右边是这一版改了什么。

- 内容按 **改动 / 扩展中心 / 平衡调整 / 修复** 分区，分区标题中文、英文原名作副标题，正文保留官方英文原文。
- 数据来自 BSG 发在 Steam 上的官方补丁公告，随包带 1.0.2.5 → 1.3.0.0 共 10 个版本的离线快照，断网也能看。
- 点「检查更新」会再抓一次最新公告并缓存到 `%APPDATA%\EFTMap\game-changes`，只增不删。
- 支持搜索（版本号、正文、中文分区名都能搜）和 `#changes` 深链。

### 安装程序重做

安装向导整体改成 Windows XP 时代的经典 InstallShield 布局：左侧蓝色品牌区、右侧白底内容、底部浅灰米色按钮条。四个页面和失败页的文案也全部重写，去掉了原来的解释性长句。

同时修掉几个实际会挡住安装的问题：

- 装之前会**自动关闭仍在运行的旧版本**（只关位于目标安装目录内、文件名属于本程序的进程，不按进程名全局杀）。
- 安装目录、截图目录支持「浏览…」图形选择，不用再手打路径；自动探测的结果会直接显示在输入框提示里。
- 创建快捷方式加了 120 秒超时和失败重试：被杀毒软件或资源管理器短暂占用 `.lnk` 时不再整台安装卡在最后一步。
- WebView2 缺失不再弹模态框打断安装，改成安装选项页里的一行说明和下载按钮。

### 其他

- **价格识别**：截图里显示名相同、实际不同物品的「?」现在可以点开，从候选里选具体是哪一个，选完整行名称、图标、价格一起切换。
- **市场大盘**：冻结了名次列，滚动时不再错行。
- **数据日期**：右上角标注当前内置数据的截止日期，和本机客户端版本区分开。
- **行情读取**：从云端拉价格时显示转圈动画，不再是一行静止的文字。

## 下载

| `EFTMap-Setup-0.2.9.0.exe` | 想要一键安装，自动建快捷方式和卸载项 |

三个版本的程序相同，只是安装方式和界面窗口不同。都不需要安装 Python。

## 注意事项

- 本工具不读游戏内存、不注入游戏进程。默认完全离线，只有「检查更新」和开启在线行情时会访问网络。
- 「更新」页的补丁正文是官方英文原文，只把分区标题做了中文对照，避免翻译走样。
- 自动截图默认关闭。它会在游戏窗口处于前台时模拟按下截图键，存在被反作弊误判的可能，介意的话保持关闭。
- 路线规划只在同一楼层沿道路寻路，跨楼层会直线连接。
