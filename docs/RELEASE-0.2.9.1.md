# 《逃离塔科夫》互动地图 · 0.2.9.1

永久免费，Windows 平台。

## 本次更新

### 顶栏菜单重排

- 「应用菜单」改名为 **设置**，并删掉其中的「文件」「工具」两个分区。
- 新增一级菜单 **小工具**：小地图浮窗与价格识别的全部设置都搬到了这里。
- 截图目录 / 日志目录设置移入 **设置 → 目录**。
- 最终顺序：地图 任务 弹药 配枪 配装 市场 更新 **小工具** **设置**。

### 属性设置

- 去掉了面板的像素风位图底板与标题栏，改成与全站一致的扁平样式。
- 左下角新增醒目的「保存设置」键：一次保存商人好感 / 藏身处设施 / 技能等级三个页签，
  写入本机并在下次启动自动沿用；保存后面板不关闭，方便继续调整并看到「已保存」提示。
- 右上角「✓ Confirm」保留原行为（保存并关闭）。

### 价格识别

- 浮窗里重名物资的黄色 **?** 徽记现在真的可以点：
  旧代码把鼠标客户坐标当屏幕坐标又换算了一次，窗口不在屏幕左上角时命中区整体偏移，
  表现为「徽记看得到、点了没反应」。修复后点击徽记会钉住候选选单，
  选中的物品/口径会立即应用到价格与每格价。
- 网页「截图识别」结果列表里的「?」候选菜单保持不变。

### 市场大盘

- 没有任何 48h 行情的板块（例如某个分类下全是无法上架跳蚤市场的任务情报）会置灰并标注
  「无行情数据」，点击不再进入 0 项的空榜单；鼠标悬停会说明原因。

### 修复

- 点「浏览…」选择截图 / 日志目录时闪一下 cmd 窗口的问题已修复（后台 PowerShell 改为无窗口启动，
  文件夹选择框照常弹出）。
- 从较老版本（0.2.7 及更早）升级安装时闪一下黑窗的问题已规避：旧卸载器的延迟删除子进程
  改为继承一个隐藏控制台，不再新建可见控制台。欢迎从旧版升级再测一次。

三个版本的程序相同，只是安装方式和界面窗口不同。都不需要安装 Python。

## 注意事项

- 本工具不读游戏内存、不注入游戏进程。默认完全离线，只有「检查更新」和开启在线行情时会访问网络。
- 属性设置按 PvP / PvE / PvPS 三个模式独立保存，保存在本机浏览器存储中（清除浏览器站点数据会一并清除）。
- 自动截图默认关闭。它会在游戏窗口处于前台时模拟按下截图键，存在被反作弊误判的可能，介意的话保持关闭。
- 路线规划只在同一楼层沿道路寻路，跨楼层会直线连接。
