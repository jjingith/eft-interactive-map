# 《逃离塔科夫》互动地图 · 0.2.9.2

永久免费，Windows 平台。

## 本次更新

### 市场列表收录全部物品

以前市场列表只列「当前有跳蚤报价」的物资，没上架的（比如实体比特币）在列表里根本搜不到。现在改成以**全量物品**为基准：

- 没有报价的物资照常出现在列表里，价格列显示「—」，名称旁标一个 **无报价** 徽记；
- 排序时缺价格的排在最后，不影响有报价物资的浏览；
- 底部统计改成「全部 N 条（有报价 M 条）」。

顺带说明抓取口径：抓取器向 tarkov.dev 请求的是全量物品 id（5498 个），落盘时只保留至少有一个价格字段的条目；列表现在不依赖这份筛选，所以尼基塔把某批散装子弹重新放上跳蚤后，下一次抓取有价即自动显示。

### 小工具改成独立页面

原来「小工具」是顶栏的一个下拉弹层，空间有限。现在升级成与地图、配装同级的**第 8 个视图**：

- 左栏是工具列表，右栏是选中工具的设置，纵向空间充足；
- 目前有小地图浮窗、价格识别两项，右侧内容与原设置面板一致；
- 记住上次选中的工具，下次打开直接回到那里；
- 以后新增小工具只需加一个列表项和一个内容页。

顶栏顺序现在是：地图 · 任务 · 弹药 · 配枪 · 配装 · 市场 · 更新 · 小工具 · 设置。

### 修复：点「更新」后立刻跳回原页面

从别的视图点「更新」（或「小工具」）时，服务端的配置回声可能比本地状态旧，一秒内把视图顶回原页面。现在本地切换视图后 2.5 秒内忽略旧配置里的视图字段，与既有的「自己刚写回配置的窗口内跳过回声」策略一致。

## 注意事项

- 本工具不读游戏内存、不注入游戏进程。默认完全离线，只有「检查更新」和开启在线行情时会访问网络。
- 市场里的「无报价」不代表物品不存在，只表示当前数据源没有它的跳蚤行情（任务物品、未上架、或刚改过可上架名单）。
- 自动截图默认关闭。它会在游戏窗口处于前台时模拟按下截图键，存在被反作弊误判的可能，介意的话保持关闭。
