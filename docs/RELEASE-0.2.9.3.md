# 《逃离塔科夫》互动地图 · 0.2.9.3

永久免费，Windows 平台。

## 本次更新

### 补丁说明会自动更新了

游戏昨天更新到 **1.3.5.0**（万圣节活动结束、性能优化、RenderStack 图形引擎、战局重连重做、
Unity 6、图鉴改动等 33 条），以前要手动点右上角「检查更新」才会出现，现在：

- 进入「更新」页时，如果本地数据缺失或超过 6 小时没检查，会**自动在后台补拉一次**，
  不用再点按钮；失败也不打扰，继续显示本地已有内容。
- 右上角「检查更新」仍然保留，想立刻确认时随手点一下即可。

### 补丁说明改为云端发布，以后不用重新打包

- 新增定时任务，每 6 小时从 Steam 官方公告抓一次，有变化才把快照提交到仓库；
  没有新补丁时不会产生空提交。
- 客户端拉取时先连 Steam；Steam 不通（被墙、抽风）会自动改读 GitHub 上的云端快照，
  再写入本地缓存。**装好这一版之后，后续游戏更新不再需要等新安装包**。
- 随包快照也更新到 1.3.5.0，新装用户离线也能直接看到这一版。

### 其他

- 补丁分区标题补充了中文对照：万圣节活动 / 性能与优化 / RenderStack 图形引擎 /
  战局重连重做 / Unity 6 引擎 / 图鉴改动。
- 状态栏会显示数据来源（官方公告 / 云端快照 / 本地缓存 / 随包快照）与最近检查时间。

### 修复：小工具里按任何按钮都会跳回市场

在小工具（小地图浮窗 / 价格识别）里改任何设置，页面会跳回市场。根因是服务端保存视图的白名单
漏了「更新」「小工具」两个视图：保存时被丢掉，配置里保留着上一次的市场视图，随配置广播把界面
切了回去。现在白名单与前端一致，停留在小工具里改设置不会再跳走。

### 新增：截图键可以在面板里手动设置

启动器移除后，小地图浮窗里的截图键提示「请在启动器里手动填写」已经失效。现在「自动截图」下面
多了一行「截图键」输入框 + 保存按钮：

- 填 `V` / `F12` / `SysReq` 等游戏内绑定名，点保存（或回车）立即写入 `auto_screenshot.key`；
- 留空保存 = 清除手动值，自动读游戏 `Control.ini` / 日志里的截图绑定；
- 下方状态行显示当前生效的键与来源（手动设置 / 游戏 Control.ini）。

## 注意事项

- 本工具不读游戏内存、不注入游戏进程。默认完全离线，只有「检查更新」、更新页自动补拉
  和开启在线行情时会访问网络。
- 补丁正文保留官方英文原文，只把分区标题做中文对照，避免翻译走样。
- 自动截图默认关闭。它会在游戏窗口处于前台时模拟按下截图键，存在被反作弊误判的可能，介意的话保持关闭。
