## 未完成 / 受数据限制

1. **25 套内置枪械预设无法还原**：上游 `containsItems` 给出的配件与本地 `slots[].allow` 不匹配。已在 `gun-presets.json` 的 `unsolved` 中列出原因与件数，不猜测。
2. **99 套上游预设未随包分发**：其基础枪械没有槽位树，无法在改装工作台还原。
3. **PVP / SCAV 价格档**：上游无独立字段，保持禁用。
4. **兑换配方折现**：没有可靠的物品→卢布换算规则，只展示配方，不计入 Final Cost 的现金价。
5. **Sell 缺价**：585 件没有可靠商人回购价，界面显示「无数据」。
6. **完全缺价**：273 件（多为任务 / 特殊物品）没有任何价格字段，界面显示缺失标记。
7. **枪械预设删除后的重新绑定 UI**：当前是明确提示 + 槽位显示「预设缺失」；没有自动重绑或批量替换功能（这是有意避免静默换枪）。
8. **正式打包与发布**：本轮只做临时目录打包检查，未覆盖正式产物。

## 存储与接口速查

- 装备预设：`%APPDATA%\EFTMap\loadout-presets.json`
- 枪械预设：`%APPDATA%\EFTMap\weapon-presets.json`
- 界面偏好：`%APPDATA%\EFTMap\eftmap.config.json`（`ui.view` / `ui.loadout` / `ui.sens`）
- 接口：`GET /api/presets?kind=loadout|weapon`、`POST /api/presets`（`action=save|delete|import`，可选 `repair`）
- 后端模块：`tools/presets.py`；前端：`app.js` 中 `ensurePresets` / `openPresetModal` 与 `#gun-view` 相关函数
