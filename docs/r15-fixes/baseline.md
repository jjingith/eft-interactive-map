## 3. 用户反馈的 6 项问题（本轮修复目标）

1. 射速不应手填，应由所选枪械决定 → 修改前无枪械选择，纯手填。
2. 目标血量样式须对齐参考图 → 修改前为横向 chip 列表。
3. 目标护甲配置须与配装工作台一致 → 修改前为独立手填层表单（字段与配装不同源）。
4. 选 Boss 后装备须限制在该 Boss 装备池 → 修改前只有一个泛化 Boss 目标，无池。
5. 多层护甲（硬插板 → 软内衬）状态传递须核验 → 修改前层间 `pen-1 / dmg×0.9` 为估算，未区分板/内衬顺序，被硬板挡住后不考虑软内衬钝伤削减。
6. 障碍物栏须位于“枪械选择”与“目标类型”之间，且机制须与护甲分开 → 修改前藏于护甲层表单之后。

- 枪械射速 / 射击模式：本地缺失 → 构建期从 `https://json.tarkov.dev/regular/items`（项目既有数据源）提取，生成 `data/gun-rates.json`。
