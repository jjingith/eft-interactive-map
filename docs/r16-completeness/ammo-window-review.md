参考图结构（逐项读出）：

1. 顶部：`未指定口径` 条 + 右侧下拉箭头（口径选择）。
2. 主体：若干行，每行 = 左侧小弹药盒图标 + 上下箭头（排序）+ 一个带下拉箭头的方形图标位 + 横贯整行的大弹体轮廓。
3. 底部：左侧弹匣图标、中间空位、右侧宽按钮 `装填弹匣 × 1`。
4. 整体为极暗的深色面板，行间用细线分隔。

## 2. 实现映射

| 参考图元素 | 实现 | 位置 |
|---|---|---|
| 顶部口径条 | `口径 · 枪械 · 弹匣 · 已装/容量` 一行（`.am-sim-loaderhead`） | `renderSimLoaderHead()` |
| 行内上下箭头 | 每段弹药左侧 `▲/▼`，整段上移/下移（`sim-mag-up/down`） | `renderSimMagList()` |
| 行内弹药图标 | 本地 `assets/icons-items/<弹药ID>.webp`（运行期零外部请求） | 同上 |
| 行内名称/规格 | 名称 + `口径 · 穿 · 伤 · 甲伤 · 初速` | 同上 |
| 行内下拉选弹 | 底部一行统一选择（`ammo-pick`，只列该枪 `allowedAmmo`） | `renderSimAmmoOptions()` |
| 底部弹匣图标 | `[data-sim="mag-icon"]`，显示所选弹匣本地图标 | `renderSimMagList()` |
| 底部装填按钮 | `装填 × N 发`（随数量输入实时更新）+ `清空` | `bindAmmoSimUI()` |
| 容量与剩余空间 | 弹匣行 `已装 X / Y 发 · 剩余 Z`，顶部同数值 | `renderSimMagPicker()` |
| 不兼容状态 | 换枪即清除不兼容弹药并提示；弹药下拉为空时禁用并显示 missing | `amSimOnGunChanged()` |

## 3. 仍然存在的差异（未实现）

1. **大弹体轮廓**：参考图每行右侧有一条贯穿的子弹剪影，实现用文本规格代替，未画轮廓。
2. **行内下拉**：参考图每行自带一个下拉箭头（可逐行改弹药类型）；实现的行是「已装类型」，改类型通过底部下拉 + 重新装填，行内只有排序/删除。
3. **"装填弹匣 × 1" 语义**：参考图一次装满一整匣；实现按「装入 N 发」执行，便于模拟部分装填。
4. **口径下拉**：参考图顶部是可切换口径的下拉；实现的顶部是只读信息条（口径由所选枪械决定），
   口径切换通过上方的「口径筛选」完成。
5. **视觉质感**：沿用项目 `am-workbench` 的暗色卡片体系（边框/字号/间距），没有复制游戏内半透明磨砂与阴影。

以上差异不影响装填功能：装入、排序、删除、容量限制、逐发消耗、逐发日志均可在浏览器中实际操作。
