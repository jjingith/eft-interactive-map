## 2. 当前版本可确认的机制（wiki verified，2026-10-23 实读）

| 部位 | 黑化后再次受击的分散比例 |
|---|---|
| 手臂（左/右） | **0.49×**，分摊到全身血池 |
| 腿（左/右） | **0.7×**（旧代码误用手臂的 0.49 —— 本轮修正） |
| 胃 | **1.05×** |
| 头 / 胸 | 黑化即死亡，不再结算 |

其他确认项：
- **正常命中不做任何部位倍率**：打手臂就是手臂掉 40，打胸腔就是胸腔掉 40；
  「70%/100%/150%」是历史版本的黑化分散倍率，不是命中倍率——两者不能混用；
- 分散是**把（伤害 × 比例）这一份分摊给其余存活部位**，不是每个部位各扣一次完整伤害；
- 黑化部位吸收至剩余 HP 的部分不分散；只有**已黑化部位再受击**时才整发按比例分散
  （击杀该部位那一发的超出部分，当前按无倍率直接分摊——社区资料未给出该发的精确规则，
  保持现状并在日志中可见 `overflow.dmg`）。

## 3. 穿过人体碰撞箱（估算模型，默认关闭）

- 现状审计：旧实现每发只结算一个部位，**不存在**「穿过手臂再打胸腔」的路径——
  既没有重复结算，也没有状态续用；
- 本轮新增 `cfg.throughBody: 'estimate'`（默认 `off`）：护甲全穿、弹体入体、目标未死时，
  弹体按 `EST_THROUGH_BODY_DMG_KEEP=0.6 / PEN_KEEP=0.6` 衰减后**作为一次新的正常命中**
  结算到续命中部位（映射：左/右臂→胸腔，左/右腿→胃，胃→胸腔；头/胸无后续）；
- 续命中**绝不套用黑化分散倍率**；不重算续命中部位的护甲（出侧护甲归 R16 的
  `exitModel` 单独负责，两者互斥触发、互不干扰）；
- 命中部位的正常伤害 **不恢复**、**不重复**：`dmgToPart` 全程只来自护甲计算后的剩余弹体。

## 4. 计算链核对结论（任务书第三节逐项）

| 检查项 | 结论 |
|---|---|
| 已被护甲消耗的伤害被重复恢复 | 无：`st.dmg` 单调不增，无任何回乘 |
| 正常胸腔命中套用肢体倍率 | 无：倍率只出现在 `applyDamage` 的「已摧毁部位」分支 |
| 普通部位命中被当作黑化溢出 | 无：只有 `p.hp <= 0` 时走 `dmg × mul` 分支 |
| 同一发子弹在护甲层间重复结算 | 无：每层只扣一次 `durDmg`，`dmgToArmor = Σ`（测试锁定） |
| 碰撞箱穿透未更新状态 | 旧实现无此路径；新增估算模型显式衰减并标注 |
| 头/胸满足死亡条件仍继续扣血 | 无：`applyDamage` 对 `target.dead` 直接返回，弹丸循环以 `!target.dead` 为界 |
| Boss / PMC 血池混用 | 无：`targetPartHp` 由目标预设逐部位给出（测试对比 Killa 210 胸 vs PMC 85 胸） |
