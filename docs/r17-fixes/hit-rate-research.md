# 命中率模拟与「账号命中率自动读取」可行性研究（R17S4）

日期：2026-10-23 · 网络：代理 `http://127.0.0.1:7896`，本地服务/CDP 直连

## 1. 本轮已实现的命中率模拟（数据完全本地、离线可跑）

- UI：「命中分布」区新增**启用命中率模拟**复选框，默认未勾选；未勾选时输入框 `display:none`（不可编辑），
  勾选后显示 0–100 输入；`amSimCfgFromUI` 对空值/非数字按 0、超范围夹到 0–100。
- 引擎：`cfg.hitChance`（0–1，未传 = 关闭）。每发独立判定：
  `chance>=1` 恒命中、`<=0` 恒不命中（**这两种边界都不额外消耗随机数**，因此 100% 与「关闭」逐发日志完全一致）；
  中间值用 `rng() < chance`，同种子可复现。
- 未命中：不进入护甲/人体结算（不扣耐久、不产生钝伤、不触发死亡），但**弹药照常消耗、射击时间照常推进**；
  掩体逻辑仍在 `resolveShot` 内执行（日志记录掩体穿透结果），只是不做人体结算。
- 日志新增「命中 / 未命中」列；未命中行部位显示「未命中」，结果列「未命中」，不写虚假穿甲/伤害；
  汇总显示「命中 X / 未命中 Y（命中率 N%）」。
- 与「固定部位 / 随机命中」互不替代：命中决定是否打中，命中后再按当前模式选部位（随机模式下未命中不发部位）。
- 未改动任何既有护甲损毁、穿透、肉体伤害公式。

## 2. 账号命中率自动读取：调查问题与结论

### Q1. 哪些日志文件包含账号 ID 和游戏会话信息？

- EFT 客户端日志目录为 `%LOCALAPPDATA%\Battlestate Games\EscapeFromTarkov\Logs\`，
  按会话生成 `application_*.log`、`notifications_*.log`、`pushes_*.log`、`traces_*.log` 等文件。
- 公开项目 **TarkovEyes**（GitHub `MelGP/tarkoveyes`，真实日志解析实现）在源码里明确要求用户选择
  「EFT Logs folder」，其唯一日志用途是 `refreshQuestLogs()`（任务状态）。
  → 说明公开可用的日志信息主要是**任务/通知/会话事件**，会话与 profile 标识出现在这些事件里。
- **可信等级：estimated**。本轮未能取得可核验的原始日志样本（fandom 403 Cloudflare、Reddit 429、
  本机无 EFT 安装），因此不把具体字段名写成 `verified`。

### Q2. 是否存在逐发射击或命中事件？

- **结论：未发现任何可靠证据。missing。**
- 依据：社区唯一的日志解析项目只用日志读任务状态；没有任何公开工具从日志统计 shots/hits；
  游戏内命中反馈（战果画面的命中部位）属于客户端 UI，不是日志事件 —— 不能把两者混为一谈。

### Q3. 是否存在可靠的账号总射击数与总命中数？

- **日志层面：missing。** 生涯统计（含 accuracy）在账号档案/游戏内统计界面，普通日志不落这类汇总。
- 即便某些 pushes/notifications 事件里带 player 统计片段，也缺少公开、可复现的字段说明 → 不能据此实现。

### Q4. 是否存在公开 API 可以稳定取得账号准确度？

- **实测：没有。**
  - `https://json.tarkov.dev/endpoints`（HTTP 200）返回 10 个端点：
    barters / crafts / hideout / items / maps / prices / prices history / status / tasks / traders / season，
    **全部是静态游戏数据，没有 profile / 账号统计端点**。
  - `https://api.tarkov.dev/graphql` 本轮返回 `GraphQL server unavailable`（GET 400，POST 同样报服务不可用）。
  - 账号统计类数据（含命中率）只在登录态下由官方 profile 接口提供，需要账号授权，无匿名公开读取路径。

### Q5. 有哪些证据证明这些数据存在或不存在？

| 证据 | 结论 | 可信等级 |
|---|---|---|
| tarkov.dev REST 端点清单（HTTP 200，逐条读取） | 无 profile/统计端点 | verified |
| GraphQL 端点本轮响应 | 服务不可用，无法作为数据源 | verified（就本轮环境） |
| TarkovEyes 源码日志用途仅任务状态 | 日志无射击/命中解析 | verified（代码可查） |
| 社区/文档关于日志含会话与 profile 标识 | 存在会话信息，但不含命中统计 | estimated |
| fandom / Reddit 访问 | 403 Cloudflare / 429 限流，未能取得 | 访问失败已记录 |

## 3. 结论与后续建议

- **不实现任何「自动读取账号命中率」功能**：没有可靠数据源，实现即造假。
- 若后续需要「从用户主动提供的统计截图导入命中率」，应作为**独立 OCR 导入**功能：
  用户手动上传/截图 → 本地 OCR 解析 → 显示解析结果与置信度（`estimated`）→ 用户确认后填入命中率；
  默认关闭、不读取日志、不联网。
- 模拟器内的命中率始终是**用户输入参数**（或固定种子下的可复现随机序列），不代表账号真实准确度。
