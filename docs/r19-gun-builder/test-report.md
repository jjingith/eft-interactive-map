## 2. 属性公式：用 373 条官方预设反证

`data/gun-presets.json` 的每条预设都记录了完整装配清单 `i` 和游戏内真值
`e`（人机工效）/ `rv` / `rh`（后坐力）/ `moa`。逐条重算：

| 字段 | 平均残差 | 中位绝对误差 | p95 | 最大 | 结论 |
|---|---|---|---|---|---|
| 人机工效 | **+0.002** | **0.000** | 0.100 | 3.000 | verified |
| 垂直后坐力 | −0.016 | 0.300 | 0.500 | 0.500 | verified |
| 水平后坐力 | −0.014 | 0.300 | 0.500 | 0.500 | verified |
| MOA | −6.374 | **2.500** | 25.620 | 42.400 | **不成立 → 不实现** |

- 人机工效的加法模型成立，且**按总重量分桶看残差没有系统性偏差**，排除"重量惩罚项"。
- 后坐力是"百分比累加后乘一次"，同一系数同时解释垂直与水平两个字段。
- MOA 无法从 `centerOfImpact` + `accuracyModifier` 反解（`moa/(coi×60)` 比值在
  0.571~39.55 浮动），按"不伪造"原则改为只展示原始散布角。

## 6. 本轮修掉的三个既有缺陷

都是在真实浏览器验收时发现的，不是单测能抓到的问题：

1. **属性行文字颜色**：`.gw-stat-num` 在 style.css 里写死 `#ededed`，R18 的主题映射
   没覆盖到，导致「基础枪械 / 改装槽位 / 已装配件」三行的值在 XP 白底上几乎看不见。
2. **候选表配件名不可见**：`.gw-row-name b` 写死 `#e6ebf2`，同样是 R18 映射遗漏，
   表格里只剩"配件"两个字。
3. **属性行重叠**：左栏只有 150px，标签过长时换行把行高撑乱；改为 `flex-wrap: nowrap`
   + `text-overflow: ellipsis`，并在窄屏隐藏差值列（`@media` 1500px 以上才显示）。
