# R19.14 布局修订：隐藏不存在的槽位格子

日期：2026-10-26
版本：`R19.14-bdf447da`（`/api/build` 实测）
范围：**只改空坐标可见性**。未改六行九列坐标、固定锚点、父子排列、顶部扩展规则。

---

## 一、需求

画布上两种「空」必须区分：

| 类型 | 判定依据 | 显示 |
|---|---|---|
| **A. 游戏里不存在的槽位** | 六行九列里的空白坐标，槽位树里没有对应节点 | **完全隐藏**：无格框、无背景、无占位卡片、不响应交互 |
| **B. 真实存在但未安装配件的槽位** | 槽位树有节点（有 sid / allow / 父子关系） | **保留空槽**：虚线框 + 槽位短标签，可点可 hover |

判定依据是**真实槽位树**，不是「当前有没有配件」。

---

## 二、修改内容

### 1. 移除 R19.13.1 引入的 54 格占位（`app.js` `renderGunTree`）

旧代码对 6×9 每个未占用坐标循环生成 `div.gw-cell-ghost`（低对比格框）。这些坐标多数**没有真实槽位**，占位格属于伪造的「像槽位的视觉元素」，已整段删除。

现在画布只渲染：
- 真实槽位卡（`gwPartCard`，来自 `L.cells` = 槽位树 `gwSlotVisible` 的节点）；
- 枪械本体（`gw-cell-body`）；
- 子弹交互格（内部功能格，不是伪造槽位）。

### 2. 移除占位格样式（`style.css`）

`.gw-cell-ghost` 可见样式（边框 + 背景）已删除，换为注释说明：
> 不存在的槽位坐标不渲染占位格框。真实空槽继续用 `.gw-part.gw-part-empty`。

### 3. 保留项（明确不动）

- 六行九列坐标系：`GW_GRID_ROWS=6` / `GW_GRID_COLS=9`，`grid-template-rows: repeat(var(--gw-rows,6), minmax(var(--gw-row-min,56px), auto))`；
- 非零行高（空行不塌缩）——**行轨道存在 ≠ 每个坐标要画格子**；
- 固定锚点（body r3c6–c8 / stock r3c9 / mag r4c7 / grip r4c8 / ammo r5c7 / charge r2c9）；
- MPR45 / Nightforce 多层上置展开规则（r2 锚定 + 子槽向左/向上叠）；
- 枪口纵向链、前握把父子链。

### 4. 验收钩子（`app.js`）

`#gw-tree` 上输出 `data-tree-slots`（可见槽位树规模）/ `data-placed-cells`（已放置格位数），供浏览器测量与 DOM 一致性对照。

## 四、回归

- `tests/test_r19_14_six_rows.py`（8 项）改写为本轮语义：
  - 行轨道固定 6 + 非零最小高度；
  - **禁止**再为不存在的槽位渲染占位格（断言 `gw-cell-ghost` 不得出现）；
  - 真实空槽可点/hover/右键；
  - 锚点坐标未动；`AM_BUILD` 与 `?v=` 同步；
  - 浏览器审计 7 项（占位 0 / 空槽可交互 / 坐标不漂 / 六行稳定 / 顶部展开 / 流程一致）。
- 3 个旧版本同步测试改为跟随 `AM_BUILD` 动态校验（不再写死小写版本号）。
- 全量：**1012 passed / 1 skipped**。

## 五、最终效果

**画布只显示真实存在的配件槽位**（已装卡片 + 真实空槽虚线框）；
**不存在槽位的坐标保持空白透明**，无格框、无背景、无占位卡片、不响应交互；
六行九列坐标系、固定锚点、多层附件扩展、父子排列全部保持不变。
