## 一、上一轮错在哪（用户已明确纠正）

R19.15.2 把「本体正上方第三个固定格位」放到了 **r2c3**（物理上在枪口一侧），并把前照门挤到 c2。
用户明确纠正为：**照门带 r2c6 / r2c7，燕尾槽基座 r2c8**。本轮按新坐标重写，r2c3 锚点已从代码中删除。

## 二、实现的固定坐标（硬性验收条件）

| 坐标 | 用途 | 实现 |
|---|---|---|
| `r2c6` | 第一个真实照门相关槽位 | `role: rearSight`，仅在燕尾槽枪 |
| `r2c7` | 第二个真实照门相关槽位 | `role: rearSight2`（独立第二照门槽或照门的真实子槽；不存在则不渲染） |
| `r2c8` | **AK 燕尾槽基座** | `role: dovetailMount`，`fixedAnchor: "r2c8"` |
| `r1c8` | 基座对应的真实光学瞄具槽 | `role: dovetailOptic`，与基座同列、正上方一行 |
| `r1c9` | 光学槽右侧的额外真实配件槽 | `role: dovetailSide`（真实存在才渲染） |

实现要点（`app.js` 阶段 2.5，紧随主体链、早于所有通用找位）：

1. 先把 `r2c8 / r1c8 / r1c9 / r2c6 / r2c7` 五格 `reserve()`，普通附件、自动找位、车道排序都进不去；
2. 基座判定仍走真实数据（`sid=mod_mount` + 父件为机匣/根级 + `allow` 里直接列 `pt=Scope`），不看枪名；
3. 瞄具槽取基座**真实子槽**，更高层用 `placeChainUpward()` 同列向上，超出顶部走 `topPad`；
4. 额外真实子槽优先 `r1c9`，再沿同列向上，绝不放到瞄具槽下方；
5. **删除** R19.15.2 的「前照门让位到 c2」补丁——前照门回到真实枪口列正上方。

同时修掉一类真实缺陷：机匣防尘盖导轨原先不满足 4.5 判据，掉到 **r4c5（枪身下方）**；新增阶段 4.45 把它锚到机匣正上方 `r2c5`（`role: receiverRail`），r2c5 被真实瞄具锚点占用时维持原车道。全量因此有 17 个导轨格上移。
