## 问题 1：Caliber / Class 浏览页过窄 + 大块空白 —— 已修复

**真实根因（实测 DOM，非猜测）**：R19.1 的浏览页是从旧版"左侧栏浏览列表"整体挪到整页容器的，
但旧规则 `.gun-workbench .gw-browse { max-height: 232px; overflow: auto; }` 一并跟了过来——
163 张卡片被裁进 232px 高的小滚动框里（首页只露出 ~3 组），`.gw-page` 其余 900px 全是空白。

**修复**：删除 max-height / overflow / 面板底色边框，浏览内容在 `.gw-page`（overflow:auto，
高度 977px@1920）内自然增长，组与组间距 14px。

**修复前后实测**（`_accept.json` views 段）：

| 1920 Class | **1660px** | 163 | 同上，按类别分组 | none |

## 问题 2：Table 表格排版 + 隐藏属性

### A. 排版（已修复）

- **根因**：旧表用自然列宽 + 数值列右对齐，`white-space:nowrap` 让每列按最长内容撑开。
- 修复：`table-layout: fixed` + `colgroup` 显式列宽（口径 64 / 类别 84 / 枪械 auto / 数值列
  44–64 / 价格 88），统一 `font: 11px/1.45 Tahoma`，**全表左对齐**（含表头，原 `.num` 右对齐
  规则删除），单元格 `text-overflow: ellipsis`；表格 `min-width:900px` 在自身容器内横向滚动，
  不撑宽页面。
- 截图：`1920-p2-table.png`（基础 9 列）、`1920-p2-table-ext.png`（扩展 14 列）。

### B. 隐藏属性（逐项调查，三种状态严格区分）

调查过程与全部证据见 **`hidden-stats.md`**（上游 26 个属性键逐一核对 + db4tarkov 官方教程
视频转录 + 社区资料检索）。结论：

| 属性 | 状态 | 实现与依据 |
|---|---|---|
| ADS Time | **已实现（估算）** | `max(0.2, 2.35 − 0.028 × 人机工效)` 秒。锚点校验：db4 AK-74 官方预设 ergo 67.5 → 本式 0.460s vs db4 显示 0.465s。系数来自社区拟合、仅单点可核对 → 标 estimated，界面徽标「≈估算」+ 悬停写明公式与校验事实 |
| 100% Headshot acc | **已实现（估算）** | 几何推导 `0.08m(头部半径) / tan(散布角)`，散布角 = centerOfImpact + 配件精度修正；假设头部宽 16cm、满散布锥 → 标 estimated |
| OverSwing | **已调查，数据不足** | db4 专有（Evo Ergo vs 超摆阈值），公式未公开 → 显示「待验证」，不填 0 |
| EvoErgoDelta | **已调查，数据不足** | 同上（Evo Ergo 权重未公开） |
| ArmStamina | **已调查，数据不足** | db4 按玩家力量等级计算，公式与输入未公开 |
| 相机后坐 / 后坐角 / 散布偏差 | **已实现（verified）** | 上游原值 cameraSnap / recoilAngle(新提取) / deviationMax / recoilDispersion 直接展示 |
| 额外审计 | deviationCurve（无法核实合成方式，未展示）、EER（配件级派生指标，范围外） | 已在 hidden-stats.md 列出 |

- 引擎接入：`gun_builder.js compute()` 新增 9 个字段，全部带 conf 徽标与 why 说明；
  配件变化时实时刷新（见下）。
- 工作台属性区新增「隐藏属性（R19.2 调查）」段落；Table 视图「扩展属性」开关追加 5 列（对裸枪）。

## 问题 4：配件图标白底 —— 已完成

- **方法**：沿用 R18.2 验证过的构建期管线（上游 `-base-image.webp` 透明底 → Alpha 包围盒 →
  等比缩放 56px → 64×64 透明 PNG，白底由 CSS 容器提供）。**不做抠图**（R18.2 已实测两条
  抠图路线全部破坏深色物品细节）。
- **覆盖**：候选集从"配装装备"扩展为 **枪械本体(163) + 全部槽位 allow 配件(1391) +
  官方预设引用配件(1548，其中 539 件不在任何 allow 列表里——Glock 准星/照门这类只在
  预设里出现的件，首版因此漏掉已补)**，共 2793 件 → 生成 **2789 张**（4 件上游 404：
  HK416A5 RAL8000 / P90 灾厄 / 杀人鲸匕首 / NKVD 芬卡刀，走既有两级回退）。
- **接线**：浏览卡片、枪械摘要、装配卡（已装件）、候选表名格四处全部走 `setGearIcon`
  （白底 PNG → 缺失回退原 webp → 再缺失隐藏）；三处容器 CSS 明确 `background:#fff`。
- **原始资源保护**：`assets/icons-items/*.webp` 一个字节没动（测试断言该目录无 PNG 混入、
  manifest 逐件记录来源 URL 与处理参数）。
- **前后对照**：`icons-before-after.png`（12 个代表位：枪管/枪口/护木/枪托/握把/瞄具/
  导轨/战术件/刺刀/枪械本体×2/准星——深色物品本身保留，仅去底）。
- **浏览器实测**：`_accept.json` icons 段——浏览卡 **163/163**、候选行 **5/5**、装配卡
  **5/5**、摘要 **1/1** 指向 `icons-items-white`（已排除空槽占位 GIF）。

## 尚未解决（如实）

1. OverSwing / EvoErgoDelta / ArmStamina：公式未公开，界面明确「待验证」，无法给出数值。
2. ADS 公式只有一个公开锚点（db4 AK-74 预设 0.465s），多点校验需要带 ADS 真值的数据集，
   当前没有；高人机枪械（>80）触达 0.2s 下限，线性式在高端失真。
3. 参考站 Buy/Ammo Drop/Sell 的完整三页签（含商人分档价、易货）：本地只有单一价格快照，
   只实现了"改装件/含枪/回收"三个真实口径，未伪造商人价。
4. 参考站的配件关系画布树（节点连线可视化）未做——本地保持纵向卡片树，递归与装卸交互完整。
