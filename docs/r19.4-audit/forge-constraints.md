# R19.4 FORGE 约束实现与验收

## 约束语义

| 约束 | 语义 | 引擎实现 |
|---|---|---|
| 弹匣容量（多选） | 生成结果中**所有**弹匣（有 cap 字段的已装件）容量 ∈ 所选集合；空集=不约束 | 贪心循环候选过滤 + checkConstraints 终检 |
| 瞄准镜 | 结果必须装有瞄具：安装路径任一段 sid 匹配 /scope/（真实 mod_scope 槽位结构） | 贪心后从 scope 槽位候选按目标得分补装 + 终检 |
| 必须包含 | 钉选件必须被安装：贪心前**预装**（走真实槽位 allow + sanitize），贪心中该槽位锁定 | 预装 + 槽位锁定 + 终检 |
| 排除 | 钉选件（含递归子槽）不得出现 | 候选过滤 + 终检 |

## 冲突处理（可读原因，停止输出伪合格方案）

- 必含 ∩ 排除 同一件 → "同一个配件同时出现在「必须包含」和「排除」里"；
- 必含件无合法槽位 → "「X」在当前枪械（含已装父件展开的槽位）里没有合法安装位置"；
- 排除件出现在方案 → "排除的「X」出现在方案里（路径）"；
- 容量越界 → "弹匣「X」容量 N 发不在允许集合 […]"；
- scope 装不上 → "方案里没有任何瞄具（…找不到可装的 mod_scope 槽位，或候选被排除）"。

违反约束的方案标红、应用按钮禁用；「应用」前用 checkConstraints 再终检一次。
