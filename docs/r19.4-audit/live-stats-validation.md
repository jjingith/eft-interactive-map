# R19.4 属性实时更新验证（F7）

单一计算源：所有 UI（条形/属性面板/对比/成本）都从 `gunCompute()` 取值，
后者每次都携带**当前装配 + 已保存模拟参数 + 已选弹药**调用 GB.compute——不存在缓存旧装配的路径。
