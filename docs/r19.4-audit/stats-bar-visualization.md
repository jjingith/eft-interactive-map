# R19.4 条纹属性条可视化（F3）

## 规则实现

| 状态 | 人机工效（高好） | 散布角/垂直/水平后坐（低好） |
|---|---|---|
| 改善 | [0..B] 蓝灰斜纹 + [B..C] 纯蓝 | [0..C] 纯蓝 + [C..B] 蓝灰斜纹 |
| 恶化 | [0..C] 纯红 + [C..B] 红灰斜纹 | [0..B] 红灰斜纹 + [B..C] 纯红 |
| 持平 | 中性单色 | 中性单色 |

- 条高 10px（加粗）；斜纹 = `repeating-linear-gradient(45deg, 当前色 0 4px, 灰 4px 8px)`；
- 基线：灰色竖线（位置按 B/量程）+ 数值区灰字"基线 X"常驻，涨跌时基线字带方向色；
- 量程固定（120/3/600/900），换枪不失真；基线始终来自当前枪械默认装配（gunDefaultBuild），
