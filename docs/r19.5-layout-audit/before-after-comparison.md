## 逐项差异消解

| 参考站要素 | R19.4（改前） | R19.5（改后） |
|---|---|---|
| 装配区组织 | 纵向递归卡片树（13+ 卡一列） | 五分区空间画布 + SVG 连接线 |
| 枪械与槽位关系 | 枪图在上方独立块，与卡片无空间关联 | 枪械居中，槽位按物理位置环绕，连线表达安装关系 |
| 空槽呈现 | 与实卡同款仅虚线边 | 虚线占位 + 槽位短标签（MUZZLE/SCOPE） |
| 卡上信息 | 无变化角标 | 人机/后坐 ± 角标（方向配色） |
| 子槽 | 纵向缩进列表 | 紧贴父件同簇成行 |
| rail attachments | 无对应分组 | 底部小字分隔带（空导轨座/内部机构） |
| 候选表位置 | 独立右栏（R19.1 起） | 保持（406–806px 随视口），点槽位即切换 |

## 残余差异（如实）

1. 参考站顶部另有可折叠**节点图视图**（点阵画布）；本地以空间画布一体化承担，未做第二种视图。
2. 参考站 LOAD VARIANT 在中栏顶部；本地等价信息（预设下拉/恢复默认）在顶栏工具条。
3. 配色为 XP Luna（任务要求保留）；参考站为暗色。
4. 参考站 FORGE 有 3D Pareto 等（R19.4 起如实不做假控件）。
