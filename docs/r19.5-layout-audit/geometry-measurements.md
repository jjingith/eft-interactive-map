# R19.5c 中栏垂直布局修复（本节为最终有效测量）

## 根因（全部为真实布局原因，无绝对定位/负边距介入）

| 区块 | 修复前 y/h | 根因 |
|---|---|---|

| .gw-loadvar | h=122 | 摘要 box 换行 82px（chips/meta 挤到多行） |
| .gw-nodecanvas | h=198 | 节点链 6 行展开超出 147 |

| #gw-focus | h=32 | 两行文本 |
| **#gw-tree** | **y=1064**（919 视口下完全在首屏之外） | 上述各块累计 ~960px |

## 修复手段（真实布局规则）

1. `.gw-stats` → 5 列密集网格（9px 字号、行高 13px、行 border/padding 清零覆盖旧规则），
   **25 个字段一个不删**，tooltip/可信度徽标保留（缩为 8px）；≤1500px 3 列、≤900px 2 列。
2. `.gw-loadvar` 固定 30px 单行（nowrap + ellipsis；重量/价格信息在枪卡与底部成本区完整保留）。
3. `.gw-nodecanvas` 固定 **147px**（与参考一致），节点链截 4 个根槽位+枪械=5 行，链内可滚。
4. `.gw-bar` 行高压缩（padding 0、字号 10px、track 8px——满足测试 ≥8px 契约）。
5. `#gw-focus` 单行 18px。

# R19.6 DevTools 逆向后的结构重排（最终测量）

## 关键发现（见 devtools-investigation/dom-structure.md）

参考站是 **Flutter Web（CanvasKit）**：body 仅 26 个节点、innerText 长度 0、
`flutter-view`/`flt-glass-pane` 存在、无独立 CSS —— **元素级 DOM/CSS 逆向不可行**。
等价证据：Flutter 语义树（201 节点，label+rect）+ 截图像素测量。

语义树实测参考几何（1920×919）：中栏面板 [480,88,512,831]；LOAD VARIANT 行 ~47px；
画布 [499,144,462,137]；属性条 5 行 @y304/316/328/340/352（**行距 12px**）；
隐藏属性块 y373–413；配件网格自 y≈400。**参考站中栏没有「整枪属性明细」块**。

## 本地重排（R19.6）

1. 隐藏属性拆出为独立 `#gw-hidden`（3 列、12px 行、10 字段 → 66px），紧贴属性条下方。
2. 画布固定 **137px**（与参考一致）；属性条行高 12px（5 行 60px）。
3. 「整枪属性明细」25 字段**全部保留**，移到配件网格之后（参考站序列不含该块）。
4. 修复隐藏块未清空导致的重复追加（渲染两次 → 22 子节点 / 126px → 11 子节点 / 66px）。

## 结论

- 中央序列与参考站一致：LOAD VARIANT → 画布 → 5 条属性条 → 隐藏属性 → 配件网格 →（明细）→ 弹药 → 成本时间线。

- 残余 46px 差异来自本地隐藏块承载 10 个字段（参考仅 5 个）与 18px 槽位焦点行。
