# R19.5d 属性条、隐藏属性与槽位网格（stats-and-slots.md）

## 隐藏属性（第五节要求）

| 要求 | 实现 |
|---|---|
| 去掉 "✓ 实测/≈ 估算" 状态徽标 | `.gw-hidden .gw-stat-conf { display:none }`（**数据未删**：`conf` 与 `why` 仍在字段上，title 保留完整来源/公式说明） |
| 保留名称/数值/单位 | 10 项全部保留：ADS 时间 s、TrueErgoDelta、OverSwing、Aim Sway %、ArmStamina s、爆头有效距离 m、相机后坐、散布偏差上限、后坐散布、后坐角 |
| 不误删 TrueErgoDelta 差值 | `.gw-hidden .gw-stat-delta { display:inline }`（换件后显示 +/− 差值） |
| 紧凑多列键值 | 3 列网格、12px 行高、76px 总高（含标题行） |
| 不拆成独立大卡 | 无边框、无背景块，仅分组容器一层 |
| 不重叠不截断 | 标签 `text-overflow:ellipsis` + title 全文 |

## 属性条 ×5

- 行高 12px（参考行距 12px）；轨道 8px（满足 R19.4 测试 ≥8px 契约）。
- 基线灰竖线 + "基线 X" 保留；蓝/红方向色 + 斜纹区间保留（R19.4 逻辑未改）。
- 换件/卸载/换弹匣/应用 FORGE 方案/恢复默认 → 整条按新装配重算（r195_accept 实测：
  右键卸载后人机 47.0→48.5 且颜色方向随之变化）。

## 槽位网格（第六节要求）

- 卡片 52×52（原 64×64），图片透明底、等比、不裁切；空格虚线 + 7px 槽位短标签（MUZZLE/STOCK）。
- 已装卡角标（人机 | 后坐）8px，超界由 band 的 11px padding 容纳，不被裁切。
- 悬停/焦点共享浮窗（`#gw-tip`）显示槽位名 + 配件名 + 增减；左键选槽、右键卸载、递归清理不变。
- 枪械卡缩至 max 232px、图 78px，仍在网格中居中并带官方预设匹配标签。
