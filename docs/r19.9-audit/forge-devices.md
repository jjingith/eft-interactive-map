# R19.9 FORGE 手电 / 激光型号选择（forge-devices.md）

## 交互（与瞄具选择器同构）

- 「战术设备」分两个独立区块：**手电**、**激光**，各显示「N 款兼容」。
- 每块包含：当前选择摘要（`当前：型号名` / `未选择 · 点下方型号指定X`）、型号列表
  （图标 + 名称 + 功能标签 `手电`/`激光`/`手电+激光`）、**清除**按钮。
- 点型号写入真实 item id（再次点击取消），选中行高亮；无兼容型号时明示"当前枪械没有兼容的X"。

## 兼容性判据（与生成同源）

`forgeDeviceCompatible()` 对每个候选调用引擎 `GB.resolveInstall`（直接槽位或自动补一级转接座），
再用 `GB.sanitize` 复核该件确实保留 —— 与 FORGE 生成/终检走同一条代码路径。
R19.8 的"任意可装配件子槽即算兼容"近似已不再用于设备列表。

## 约束链路

UI → `cons.deviceIds=[选定 id…]` → `optimize` 必装预装（`lockedPaths` 锁定直装槽位与转接座槽位，
贪心不得替换）→ 每方案 `checkConstraints` 逐件校验 → 结果行显示型号名或
`未满足（要求 型号名）` → 应用前终检。

## 浏览器实测（AK-74）

| 项 | 结果 |
|---|---|
| 手电列表 | 9 款兼容 |
| 激光列表 | 17 款兼容 |
| 选中 | `Glock GTL 21 战术手电激光组合` → 摘要显示型号、行高亮 |
| 生成 | 4 方案：1 个满足并显示型号名；3 个显式报"未装入方案…（可能被其它配件选择占用或被转接座替换）"并禁用应用 |
| 应用 | applied，装配树/属性/成本同步刷新 |
| 控制台 / 外部请求 | 0 / None |

并非所有权重方案都能容纳所选型号——这是真实的槽位/转接座取舍，引擎与 UI 都显式报告，
不会静默返回不含该型号却标为合格的方案。
