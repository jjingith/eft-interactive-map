轨道 `width:100%`；数值列固定 104px 右对齐（改前为 `auto`，文本变长即挤压轨道，

## 3. 基准值来源与位置（四枪实测）

基准 = **当前枪械原厂默认装配**（`gunDefaultBuild` → 官方 defaultPreset 的 installed），
经**同一 compute 引擎**计算；R19.9 起基准同样携带弹药（未手选时回落 `gun-stats.da`），
初速基准不再为空。基准竖线位置 = `(B−lo)/(hi−lo)`，与当前值同尺度、独立计算，不随当前值移动。

## 4. 口径与核验说明

- 数值全部来自本地 `data/gun-presets.json`（官方 defaultPreset）+ 引擎计算，
