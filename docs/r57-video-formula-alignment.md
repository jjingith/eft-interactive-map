### 1.1 `子弹对护甲耐久伤害.png` —— 护甲耐久伤害（甲伤）


### 1.2 `减伤公式 .png` —— 减伤（Swift 代码页）

逐字（保留缩进）：

```swift
if didPenetrate {
    let multiplier: Double = (pen / armorResistanceFactor).clamped(to: 0.6...1.0)

```

- `clamped(to: 0.6...1.0)`：区间 0.6 ~~ 1.0（左闭右闭）。

### 1.3 `减伤公式2.png` —— 减伤公式（幻灯片）

标题：`减伤公式`；标签：`armorResistanceFactor`

逐字：

```
满耐久的情况下，护甲抵抗系数为：护甲等级 × 10 + 12.5
例如，四级甲的护甲抵抗系数是 4×10+12.5=52.5
子弹穿透力 ÷ 护甲抵抗系数 × 子弹肉伤 = 实际伤害
clamped(to: 0.6...1.0)   这步得出的数值只能在0.6-1.0之间
                         （最多减伤40%，高级弹无额外伤害）
```

标注：`穿透力`（分子）、`对肉体伤害`（子弹肉伤）。

> 注：mp4 内同一页在 t≈92 s / t≈1316 s 出现两次，t≈92 s 那次把公式写成 `4×10+2.5=52.5`（漏了「1」，与 52.5 不符，属画面笔误）；t≈1306 s 那页为 `4×10+12.5=52.5`。以 12.5 为准。

- 本 mp4 全片按 ≤5 s 抽帧（0–1404 s）+ 关键段 0.5–2 s 加密抽帧后，**没有检到「8 点钝伤 → 加二层降到 1 点」这一实验画面或口播**。
- 最接近的三处原文：
  1. `t305`：大口径步枪弹的钝伤带为 `8-13`（8 点钝伤的量级来源）；
  2. `t1054`：同一部位由「单插板」改为「插板+内衬」时，钝伤从「正常钝伤」变为「额外 50% 钝伤」（方向相反：加层是变多，不是降到 1）；
  3. `t1346`/`t1350`：同一部位两层以上防护时「减伤也会计算两次」。
- 该条数值实验更可能出自同系列**上集**（视频 0:08 字幕明确说「在一年之前的护甲机制视频里边」）。本轮不臆造，标为**缺失证据**。

## 4. 重点问题：视频的「防护能力/抵抗系数」定义与耐久关系

### 4.1 视频的定义（逐字 + 内部自洽性）

1. `t8`：「护甲防护力与护甲剩余耐久成正比关系」→ **防护力 P(d) ∝ 剩余耐久百分比 d**。
2. `t8`：「当穿透力 = 护甲防御力时，减伤幅度为 20% 左右（平均 15%~25%）」。
3. `t92/t1306`：「满耐久的情况下，护甲抵抗系数为：护甲等级×10+12.5」。
4. `t1322`：「只要子弹穿透高于护甲等级×10+13 的就不存在减伤了」。

把 2、3、4 放在一起，可唯一解出视频口径：

```
防护力       P_v(d) = 10·c·(d/100)          // c = 护甲等级，d = 剩余耐久百分比
抵抗系数     R_v(d) = P_v(d) + 12.5 = 10·c·(d/100) + 12.5
减伤系数     m      = clamp(pen / R_v(d), 0.6, 1.0)
```

验证三条：
- 满耐久 → R=10c+12.5（例：4 级 52.5）✔
- pen = 防护力 = 10c（满耐久）→ m = 10c/(10c+12.5)：4 级 40/52.5=0.762 → 减伤 23.8%（「20% 左右、15–25%」）✔
- pen = 10c+12.5（即比防护力高 12.5）→ m=1 → 0% 减伤（「差距 12~13 点」）✔

也就是说视频里 **「防护能力」= 等级×10×耐久%**，**「抵抗系数」= 防护能力 + 12.5**，两者差 12.5；甲伤公式用前者，减伤公式用后者。

### 4.2 与 `FactorA` 的等价性

代码：

```
FactorA(d) = (121 − 5000/(45+2d)) · c · 0.1
R_code(d)  = FactorA(d) + 12
m_code     = clamp(pen / R_code(d), 0.6, 1.0)
```

把 `FactorA` 改写成 `10·c·f(d)`：

```
f(d) = (121 − 5000/(45+2d)) / 100
```

对比视频 `f_v(d) = d/100`：

| d（剩余耐久%） | f(d) 代码 | f_v(d) 视频 | R_code（4级） | R_v（4级） | 差 |
|---|---|---|---|---|---|
| 100 | 1.0059 | 1.00 | 52.237 | 52.5 | −0.263 |
| 80 | 0.9661 | 0.80 | 50.644 | 44.5 | +6.144 |
| 60 | 0.9070 | 0.60 | 48.279 | 36.5 | +11.779 |
| 50 | 0.8652 | 0.50 | 46.607 | 32.5 | +14.107 |
| 40 | 0.8100 | 0.40 | 44.400 | 28.5 | +15.900 |
| 30 | 0.7338 | 0.30 | 41.352 | 24.5 | +16.852 |
| 20 | 0.6218 | 0.20 | 36.871 | 20.5 | +16.371 |
| 0 | 0.0989 | 0.00 | 15.956 | 12.5 | +3.456 |

**结论：不是等价形式。**

- **满耐久（d=100）可以视为等价**：误差来自两处常量（`FactorA` 给 1.0059×等级×10，视频给 1.0×；`+12` vs `+12.5`），4 级合计只差 −0.26（−0.5%）。
- **耐久一旦下降就不等价**：视频是线性，代码是凸曲线。60% 耐久时 4 级抵抗系数 48.28 vs 36.5（+11.8）；30% 时 +16.9。方向是**代码护甲更强**（抵抗系数更高 → 减伤更大 → 打出的伤害更低）。
- 换算成「怎么改才会等于视频」：把 `FactorA` 换成 `10·c·(durPct/100)`，并把 `+12` 换成 `+12.5`。仅替换常量（12→12.5）只能修满耐久那 0.26，修不了低耐久的大偏差。

### 4.3 满耐久实弹复算（与视频三个例子）

| M80（41 穿 / 80 肉）打 4 级甲 | 41÷52.5×80 = 62.5 | 41/52.237×80 = 62.79 | +0.29 |

## 5. 最可能导致用户觉得「算错了」的一处

**减伤公式的耐久项（`combat_sim.js#L34-L36` 的 `(121 − 5000/(45+2d))`）+ `#L39` 的 `+12`。**

- 满耐久时它几乎等于视频的 `等级×10+12.5`（差 0.26），所以拿全新甲验算会觉得「一致」；
- 但耐久一掉，代码仍保留很高的防护力：80% 耐久时 4 级抵抗系数 50.64（视频 44.5），60% 时 48.28（视频 36.5），30% 时 41.35（视频 24.5）。
- 直接后果：同一发 M855A1（44 穿）打 4 级甲——
  - 100% 耐久：41.27（视频 41）✔
  - 80% 耐久：44/50.64×49 = **42.6**（视频 44/44.5×49 = **48.4**，差 −5.8，约 −12%）
  - 60% 耐久：44/48.28×49 = **44.6**（视频已无减伤 = **49**，差 −4.4）
- 也就是说：**新甲准、旧甲偏「肉」**，中耐久段伤害被少算 10% 左右——这正是「按视频公式手算和模拟器对不上」时最容易被抓到的点。

次要但同样显眼的一处：**穿透概率默认走 Desmos 模型（`app.js#L20984`），而视频给的实测表（27/40/59/80/85% 与 52/62/72/84/88%）被放在 `#L20990-L21004` 却没启用**。满耐久 4 级甲、pen=37 时，默认模型 55.3% vs 视频表 27%，差一倍以上。
