## 0. 结论（先看这里）

1. **站点第二层钝伤不是任何「二次衰减」，而是「用穿透路径残量重算一遍公式」——第四种规则 H4。**
   对第 n 层：

   ```
   B_n = BT_n(×0.6 若为插板且链上存在非插板) × clamp(1 − 0.03×(FactorA_n − P_{n−1}), 0.2, 1) × D_{n−1}
   (P_{n−1}, D_{n−1}) = (P_0, D_0) × Π_{k<n} RF_k
   RF_k = clamp(P_{k−1} / (FactorA_k + 12), 0.6, 1)
   ```

   其中 `P_0 / D_0` 是弹药原始穿透/伤害，`RF` 是每层减伤系数。**第二层的输入是「上一层的穿透残留伤害 D₁」，不是「上一层的钝伤 B₁」。**

2. **H4 与站点逐位吻合**：47 组双层样本，`max |误差| = 1.44e-6`、`mean = 1.85e-7`、`max 相对误差 = 1.32e-5%`，**47/47 组落在 0.01 以内**（残差只是接口 float32 的舍入）。

3. **现在的 `bluntCarry`（H1）与站点不一致**：0/47 组吻合；`mean |误差| = 5.27`（平均相对 **89.5%**），`max = 12.84`（97.4%）。典型一例：站点 4.759 → **5.340**（第二层反而更大），`bluntCarry` 给 **0.471**。

4. **H2（固定系数）也不是规则**：`k=0.6` 平均误差 47.3%，`k=0.18` 82.9%，`k=0.125` 88.1%；即使按每个组合单独最小二乘拟合 `k`，`k` 也在 **0.506–1.526** 之间漂移，平均误差仍有 22.1%。H3（只乘本层 BT）与 H1 几乎同值，0/47。

5. **用户锚点「8 点 → 加二级面罩 1 点」只能由 H1/H3 复现，站点 H4 复现不了。**
   用站内可复现的 8 点前提：`.308 ME LOKT`（P24/D96）+ Altyn 五级面罩 10% 耐久 → 第一层 **7.603**（界面 `toFixed(0)` 显示 8）；再加二级面罩后，**站点 H4 = 6.059（显示 6）**，**H1 = 0.753（显示 1）**。
   即：站点算的是「穿透前层后，被本层挡下」的支路；视频锚点是「第一层挡下后，钝伤继续传入第二层」的另一条支路。**两者语义不同，不能拿站点数字直接否定 `bluntCarry`，但也不能说 `bluntCarry` 已被站点证实。**

6. **建议**：不要把 `bluntCarry` 直接替换成 H4。若产品目标是「和站点计算器数字一致」，加一个 `site` 模式按 H4 算；若目标是复现游戏视频锚点，保留 H1 并明确登记为「视频口径、站点未支持」。伪代码见 §8。

| 可复现性 | 同一输入多次请求返回同值（如 Altyn 单独 100% 在各组合中均为 `4.759112`）；接口为确定性计算，不是随机抽样 |
| 精度 | 接口返回 float32，6–7 位有效数字；H4 残差 1e-6 量级即舍入误差 |
| 钝伤定义 | 与 `Ballistics.cs` `BluntDamage` 一致：`BT × median(0.2, 1−0.03×(FactorA−P), 1) × D`；`FactorA = (121 − 5000/(45+2×dur%))×AC×0.1` |

**三种假设的准确写法**（用于残差表）：

- **H1（现有 `bluntCarry`）**：`B₂ = B₁ × BT₂_eff × clamp(1−0.03×(FactorA₂−P₀),0.2,1)`。上一层钝伤 × 本层 BT × 本层 scale（用**原始** P₀）。
- **H2（固定系数）**：`B₂ = B₁ × k`。分别试 `k=0.6 / 0.18 / 0.125`，以及按组合最小二乘拟合的 `k`。
- **H3（只乘 BT）**：`B₂ = B₁ × BT₂_eff`，不重算 `FactorA₂`。
- **H4（站点实际规则）**：`B₂ = BT₂_eff × clamp(1−0.03×(FactorA₂−P₁),0.2,1) × D₁`，其中 `D₁ = D₀×RF₁`、`P₁ = P₀×RF₁`。

> `BT_eff`：当某层是插板且整个 `armorLayers` 里存在任意非插板层时，该插板 BT 乘 `0.6`（`Ballistics.cs:977-980`）。这与现有引擎的 `SOFT_LINER_PLATE_BLUNT_MUL` 同值，但站点判定不看部位/方向/耐久。

| H3 | `B1×BT2` | 12.8448 | 5.2278 | 97.36% | 88.69% | 0/47 |
| **H4** | `BT2×scale2(P1)×D1` | **1.44e-06** | **1.85e-07** | **1.32e-05%** | **3.02e-06%** | **47/47** |

全局最小二乘 `k = 0.83167`；但它只是把 H1 的偏差平摊，逐组残差仍可达 7.21（84.5%）。

## 5. 第四种规则（站点实际规则）

### 5.1 函数形式

设第 k 层（k=1..n）：

```
FA_k   = (121 − 5000/(45 + 2×durPct_k)) × AC_k × 0.1
bt_k   = BT_k × (0.6 若 isPlate_k 且链上存在非插板层)
scale_k= min(1, max(0.2, 1 − 0.03×(FA_k − P_{k−1})))
B_k    = bt_k × scale_k × D_{k−1}
RF_k   = min(1, max(0.6, P_{k−1}/(FA_k + 12)))
P_k    = P_{k−1} × RF_k
D_k    = D_{k−1} × RF_k
```

初始 `P_0 = 弹药穿透`、`D_0 = 弹药伤害`。**每一层的 `B_k` 都是独立重算，不引用 `B_{k−1}`；层间只通过 `RF` 连乘的 `P/D` 传递。**

### 5.2 逐项验算（与站点原始值对照）

| 场景 | 站点 B2 | 用 H4 手算 | 差异 |
|---|---|---|---|
| `ALTYN5+MASK2`，ME308，100/100 | 5.339676 | `0.099×1×53.9361`（P1=28.3165 < FA2=20.08 → scale=1）= **5.3397** | ~0 |
| `ALTYN5+MASK2`，LOWPEN，100/10 | 3.5640 | RF1=0.6 → D1=36；FA2(10%)=8.815，P1=5.4 → scale=0.8975；`0.099×0.8975×36`=**3.5640** | 0 |
| `PLATE5+SOFT2`，ME308，100/100 | 9.708502 | 插板 BT 18×0.6=10.8；RF1=0.6742 → D1=53.9361；第二层 soft scale=1；`0.18×53.9361`=**9.7085** | ~0 |
| `SOFT2+PLATE5`，ME308，100/100 | 6.489698 | 第一层 RF=1 → D1=80；第二层插板 BT×0.6=10.8，scale=0.7511；`10.8×0.7511×80`=**6.4897** | ~0 |
| 三层 `ALTYN5+MASK2+MASK2` | 4.7591 / 5.3397 / 4.7076 | 第 3 层：RF2=0.8816 → D2=47.5516；scale=1；`0.099×47.5516`=**4.7076** | ~0 |

### 5.3 关键行为（与直觉相反，但是真的）

- **第二层钝伤经常比第一层更大**：`ALTYN5+MASK2` 4.759 → 5.340。原因是 H4 用 `D₁`（≈0.67×D）乘第二层 `BT`，而不是用 `B₁`（≈0.06×D）再乘一次。
- **第三层不一定继续减小**：三层样本 5.3397 → 4.7076（因第二层 `RF` 又削掉一部分 D）。
- **改变第二层耐久不一定改变 B2**：当 `P₁ ≥ FA₂` 时 `scale` 被夹到 1，B2 只剩 `BT×D₁`（表 4–5、14–15 行）。
- **站点单发模型是无条件双分支**：每层都会先乘 `RF` 再进入下一层，不管这一发在实际单次抽样里是穿还是挡。因此 H4 描述的是**「假定穿透前层、再被本层挡下」的支路**，不是「第一层挡下、钝伤继续传递」的支路。

## 6. 三种假设为什么都对不上

- H1/H3 把「上一层钝伤」当输入，站点把「上一层穿透残留伤害」当输入。二者量级差一个 `D/B₁` 倍数；在本矩阵中 `D/B₁` 约 10–20 倍，所以 H1 普遍偏小一个数量级。
- H2 试图用一个常数吸收 `BT₂×scale₂×D₁/B₁`，但 `scale₂` 随 AC/耐久/P 变化，`D₁/B₁` 随层 1 的 RF 变化，所以固定 `k` 必然失败；按组合拟合 `k` 也只是把每组压成一个数，`k` 本身从 0.506 漂到 1.526。
- H3 等于 H1 去掉 `scale₂`，只在本层 `scale₂=1` 时与 H1 同值；本矩阵大多数高穿样本恰好 `scale=1`，所以 H1/H3 的平均误差几乎一样（89.5% vs 88.7%）。

### 7.1 用站内可复现的真实前提

|---|---|---|
| 第一层单独钝伤 | 7.6032 | **8** ✔ 与口述「8 点」一致 |

| 同场景·H3 | 0.7527 | 1 |

若第一层取 100% 耐久：单独钝伤 1.6052 → 显示 2，不是 8；取 50%：3.2104 → 显示 3。**「8 点」在这组物品/弹药下对应的是低耐久（约 10%）的第一层**；视频未给耐久，这是最可复现的还原。

### 7.2 归一化前提（只看 8→1 的比例）

强制 `D=100、P=60、第一层 AC5 BT=8%、scale=1`（B1=8），第二层 AC2 BT=9.9%：

| 假设 | 第二层值 | 显示 |
|---|---|---|
| H1 | 0.792 | 1 |

| H2（k=0.125） | 1.000 | 1 |

若第二层换成三级「Atomic Defense CQCM 骷髅面具」（AC3，BT=19.8%）：H1 = 1.227（显示 1），H4 ≈ 10.9。

## 8. `bluntCarry` 是否站得住 + 最小改动方案

### 8.1 判定

| 问题 | 结论 |
|---|---|
| 单层钝伤是否与站点一致 | **一致**（单层基准全部与 `BluntDamage` 公式逐位吻合） |
| 多层第二层钝伤是否与站点一致 | **不一致**（H1 0/47，平均相对误差 89.5%，最大 12.84 点） |
| `bluntCarry` 是否复现用户锚点 | **是**（0.753 → 显示 1，与「8→1」一致；BT=12.5% 时为 1.000） |
| 站点是否复现用户锚点 | **否**（同场景 6.059，或归一化 9.535） |
| 站点是否证明 `bluntCarry` 是游戏真实规则 | **否**。站点模拟的是另一条支路；两者不是同一个物理场景 |

所以：`bluntCarry` 不是「站点公式的实现」，而是「视频锚点推导的单次抽样模型」。它站得住的条件是**产品目标对齐视频/游戏锚点**；如果目标对齐站点计算器的逐层数字，它站不住。

补充一个容易忽略的细节：现有引擎在「第一层穿透、第二层挡下」的路径上，`bluntCarry` 仍为 `null`，第二层钝伤 = `st.dmg × bluntFactor`，其中 `st.dmg` 已被第一层 `RF` 削减——**这条路径本来就等价于 H4**。引擎与站点的分歧只发生在「前面某层已经挡下」之后（`bluntCarry` 非空，改用 `bluntCarry × factor`）。因此最小改动不是重写整个钝伤链，而是只改「已挡下后」的递推基准。

### 8.2 建议（伪代码，不改现有代码）

**方案 A：保持现有 H1，明确标注口径。** 最小改动为零，只在 UI/文档标注「多层钝伤为视频口径，站点计算器不可直接对照」。

**方案 B：增加 `site` 模式，按 H4 计算。** 只有用户显式选择「站点口径」时启用。
最小改动版本（保留现有循环结构）：在 `blocked` 分支把 `bluntOut = bluntCarry * bluntFactor` 改为 `bluntOut = st.dmg * bluntFactor`；若要让 `st.dmg/st.pen` 在挡下后也继续衰减，再补 `st.dmg *= rf; st.pen *= rf;`（仅 `siteMode`）。下面是完整口径：

```
// siteMode = true 时
st.pen = P0; st.dmg = D0
lastBlunt = null
for (var i = 0; i < layers.length; i++) {
  var L   = layers[i]
  var durPct = L.dur / L.durOrig * 100
  var bt  = L.bluntThroughput
  if (L.kind === 'plate' && layers.some(x => x.kind !== 'plate')) bt *= 0.6   // 站点是全局 Any
  var fa  = armorFactorA(L.cls, durPct)
  lastBlunt = bt * clamp(1 - 0.03 * (fa - st.pen), 0.2, 1) * st.dmg   // ← 不再用 bluntCarry
  var rf  = clamp(st.pen / (fa + 12), 0.6, 1)
  st.pen *= rf; st.dmg *= rf                                           // ← 无论挡/穿都削
  log.layer(i).bluntOut = lastBlunt
}
dmgToPart = lastBlunt   // 站点不定义“总伤害”；这里对应“最后一层钝伤”行
```

注意三点：

1. 方案 B 会改变单次抽样语义：被挡下的子弹也会在后续层按 `RF` 损失 D。若只想让「显示数字」对齐站点、不影响弹道判定，应把 `lastBlunt` 与伤害分支拆开，仅用于展示。
2. 站点插板 ×0.6 的条件是 `armorLayers.Any(!isPlate)`（全局，不看部位/方向/耐久）；现有引擎 `hasNonPlateBacking` 更严。要逐位对齐站点，判定也要放宽。
3. 站点没有「人体总伤害」概念，只有逐层结果；如果 UI 必须给一个数，需明确约定取最后一层 `BluntDamage`（这与现在的 `bluntCarry` 收束方式相同）。

**推荐**：默认保留 H1（保住视频锚点），新增 `site` 口径开关；不要静默替换。若产品明确要求「与 tarkovgunsmith 计算器一致」，则默认切 H4，并在 UI 说明「站点口径下 8→1 锚点会变成 8→6」。

## 9. 限制与未决

1. **物品身份**：「二级骷髅面罩」在本地数据中没有完全同名的 class-2 条目；本次用 class-2 / BT 9.9%（Tac-Kek 级）为主，另给 class-3 / BT 19.8%（Atomic CQCM 骷髅）作为备选。两者 H1 都落在 1 点附近，H4 都在 10 点以上。
2. **8 点的来源**：Marlin `.308 ME`（D=80）打 Altyn 100% 只有 4.76 点；能复现 8 的是 `.308 ME LOKT`（D=96）+ 约 10% 耐久。视频未给弹药/耐久，本文如实给出两种可复现路径，不把 8 当作唯一解。
3. **材质**：钝伤公式不含材质，所有样本 `armorMaterial=7`；材质只影响甲伤字段，未纳入结论。
4. **部位/方向**：站点接口没有部位/方向参数，插板 ×0.6 只看 `isPlate` 全局；现有引擎按部位/方向过滤，二者在这类跨部位组合上可能不同。
5. **抽样范围**：47 组双层 + 42 组单层 + 1 组三层；未穷举所有 AC/BT/耐久，但覆盖了 `scale` 的 0.2 夹紧、1.0 夹紧、`RF` 的 0.6 夹紧与 1.0 两端的全部边界。
6. 未重建 `dist/release`，未 git 提交；本次结论只来自站点接口实采样与 `Ballistics.cs` 对照。
