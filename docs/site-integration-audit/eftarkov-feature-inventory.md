# eftarkov.com 功能清单（R20 第一阶段 3.3）

> 站点：`https://www.eftarkov.com/`（逃离塔科夫中文 Wiki）
> 取证方式：真实 Chrome 进入 10 个页面 + 首页 122 条链接全文归类 + 截图（`tools/r20_site_probe.py`）
> 结论口径：**已核实**＝本次实测；**观察推断**＝从链接/标题推断；**未知**＝未验证

## 0. 站点技术事实

| 事实 | 证据 | 影响 |
|---|---|---|
| **服务端渲染的 nginx 站点** | `server: nginx`；首页 HTML 76,970 bytes 内含公告/补货倒计时/最新任务/服务器状态 | **DOM 可直接解析**，是本轮唯一「可结构化取数」的参考站 |
| 单页请求量 29–79，**全部同域** | 9 个页面实测 host 仅 `www.eftarkov.com` | 无第三方接口、无 CDN 依赖 |
| **无公开 JSON API**（未发现） | 每页仅 1 条疑似统计/接口 URL，其余为页面与静态资源 | 取数只能解析 HTML；**版权风险需先确认** |
| 内容为中文译文 + 自建图片 | 标题如「逃离塔科夫中文Wiki」；图片路径 `/uploads/trader/<id>.webp` | 译文与图片**不是**可自由复制的素材 |
| 有账号体系 | `/login` `/register`，右上「登录/注册」 | 浏览无需登录 |
| 有 PVP/PVE 切换 | 顶栏 `PVP▾` 下拉 | 与现有三模式设计可对齐 |

## 2. 页面清单（按家族）

> 「链接数」= 首页可点到的该类链接数，用于衡量该家族在站内的体量。

### 2.1 任务族（强项，与本项目重叠最大）

| 页面 | 体量 | 实测证据 | 与现有重叠 |
|---|---|---|---|
| `/task` 任务列表 | 96 按钮 / 112 链接 | 标题「任务列表」 | **高**（现有 `tasks` 视图） |
| `/task?trader=<商人>` 按商人筛 | 9 个商人 + 竞技场 + BTR + 竞技场任务 | 链接含 `Prapor/Therapist/Fence/Skier/Peacekeeper/Mechanic/Ragman/Jaeger/Lightkeeper/BTR司机/竞技场裁判/arena` | **高** |

## 3. 与本项目的关系判断

| 判断 | 依据 |
|---|---|
| eftarkov 是**中文 Wiki 型**站点，功能覆盖比 db4 窄（无枪械构建、无装备纸娃娃、无日志解析），但在**任务树、藏身处、经济三件套**上更完整 | 页面清单实测 |
| 它**没有**枪械构建器、没有逐发模拟、没有弹药距离/护甲矩阵 | 未发现对应入口（**未穷举**，但导航已全量归类） |
| 它的价值主要是：**中文化术语对照** + **任务树/藏身处/经济页的交互形态参考** | 观察 |
| **不可直接搬运**：正文是其译文、图片是自建素材，许可未标注 | 任务书 2.4 |
