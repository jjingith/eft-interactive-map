# 研究局限与未验证项（R20 第一阶段 3.3 收尾）

> 任务书要求：「标记无法访问、无法验证或数据来源不明的内容」。
> 本文档把这些**全部列出来**，避免把"页面能打开"写成"功能已验收"。

## 1. 站点侧未验证

| # | 未验证内容 | 原因 | 需要什么才能验证 |
|---|---|---|---|
| L1 | db4tarkov **单枪构建页**（点进某把枪后的选槽/装件/属性对比/保存） | Flutter canvas 导航项不在语义树中，坐标点击命中不稳定（本轮实测 2 次未命中） | 人工录屏或 1 次有人值守的坐标标定 |
| L2 | db4 **物品详情 / 任务详情 / Boss 详情** | 同上；且每页 30–45s 初始化 | 同上 |
| L3 | db4 `Gunsmith / TierMaker / Streamer / Variant / Saved` 五个视图各自内容 | 仅从语义树读到标签 | 逐个点击（受 L1 限制） |
| L4 | db4 登录后行为（保存进度、云同步） | **未登录**（任务书 2.4 不绕过任何访问控制） | 需用户自行登录后授权观察 |
| L5 | db4 Boss 刷新概率的完整面（是否分 PvE/PvP、是否为赛季限定） | 只看到 2 条语义样本 | 需可交互进入（受 L1 限制） |
| L6 | eftarkov `/price` `/ranking` `/collection` `/prestige` `/spawn` `/btr` `/goon` `/achievement` `/skill` 页面内容 | 本轮只按"价值密度"选了 9 页实测 | 逐页打开（成本低，约 1 分钟/页） |
| L7 | eftarkov 物品详情页字段 | 同上 | 同上 |
| L8 | eftarkov 登录/收藏/评论功能 | 未登录 | 需授权 |
| L9 | 两站 **robots.txt / 服务条款 / API 条款** | 未逐条核对（首页与关于页未见 license） | 人工法务确认；这是"能不能用"的最终依据 |
| L10 | 两站在**不同网络环境**（尤其中国大陆直连）的可达性 | 本机直连成功，未做多环境对比 | 多网络采样 |
| L11 | 两站数据相对游戏版本（1.3.0.0）的滞后程度 | 无法从页面判定 | 与官方 patch notes 对表 |

## 2. MCP 侧未验证

| # | 未验证 | 原因 |
|---|---|---|
| M1 | `capture_browser_scenario`（MCP 自启浏览器 + actions 点击） | canonical schema 未公开（compact profile），首次调用风险高；已用本机 CDP 覆盖同类能力 |
| M2 | `export_web_scripts` / `recover_javascript_sources` | db4 的 `main.dart.js` 18.5MB 且无 sourcemap，收益≈0 |
| M3 | `observe_web_session`（用户手动操作窗口） | 本轮用脚本主动导航已足够 |
| M4 | `inspect_web_page` 的请求体/响应体 | 默认 `policy_filtered`，正文需显式授权；且任务书要求不碰私有后端 |

## 3. 方法学限制（会影响结论强度）

| # | 限制 | 影响 |
|---|---|---|
| R1 | **Flutter canvas 站点无法做 DOM 断言**，只能"语义标签 + 截图" | db4 的所有结论强度 = "观察到"而非"可结构化验证" |
| R2 | 语义树是**当次快照**，导航项时有时无 | 不能据此断言"某控件不存在" |
| R3 | 每个 db4 页面需 30–45s 初始化，共 12 页 | 未做"同页多次采样"，未验证稳定性 |
| R4 | 截图是**视口截图**（非整页），长页面底部未取证 | 长表格末端内容未核对 |
| R5 | 参考站内容随游戏版本变化 | 本报告对应 db4 `v2026.10.28-0` / 游戏 `1.2.0.0`；eft 未标注版本 |
| R6 | 未做"数据正确性"交叉验证（如弹药穿深是否与游戏一致） | 本站只审"功能形态"，不背书其数据准确性 |

## 4. 合规声明

1. 本轮**未抓取、未保存**任何参考站的业务数据；`raw/*.json` 只含页面结构元信息（URL/标题/语义标签/请求 URL 与 host/控制台文本），**不含数据内容、不含 cookie、不含请求头**。
2. 本轮**未登录**任何站点，**未绕过**任何访问控制、验证码或反爬机制。
3. `screenshots/*.png` 是**功能研究用途的界面截图**，包含第三方站点界面元素；若未来要对外发布审计报告，需先确认截图使用许可。
4. 参考站的**图片/地图素材/译文一律未复制**到本项目。
5. 现有项目底图许可为 **CC BY-NC-SA 4.0**（`data/meta.json` 记录），意味着**当前项目不可商用**——这一约束不因本轮研究而改变。
