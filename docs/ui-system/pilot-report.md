# 试点改造报告：任务模块「商人任务中心」（R19.24）

- 试点页面：主程序 → 任务 → 商人任务（`index.html#tasks` → `.tk-pane-traders`）
- 选择理由：它是当前控件密度最高的页面之一（工具条 + 表格 + 状态标签 + 交互提示 + 需要弹窗解释数据），
  且直接覆盖 §8 要求的全部要素；同时它属于刚交付的 R19.23 模块，改造风险可被既有 58 项验收覆盖。
- 原则：**只换"怎么画"，不换"怎么算"**。筛选、排序、模式隔离、进度、导入导出逻辑一行未改。

## 一、改造前 / 改造后对照

| 方面 | 改造前（R19.23） | 改造后（R19.24） |
|---|---|---|
| 表格 | 手写 `div.tk-table > div.tk-tr > span.tk-td`，列宽写死在 `.tk-tr { grid-template-columns: … }` | `GWUI.table({colTemplate})` → `.ui-table` + `--ui-table-cols`；保留 `tk-table/tk-tr/tk-td` 作为结构钩子 |
| 表头 | `.tk-th` 自带渐变，无粘性 | `.ui-table__head` 粘性 + 统一渐变 + 1px 深边 |
| 状态列 | 纯文字 + `.tk-td-status.is-done` 三行颜色规则 | `ui-badge`（ok/info/danger/muted），带文字与 `title` |
| 排序 | 手写 `<label class="tk-sel"><select>` | `GWUI.select` + `GWUI.toolbar`（保留 `#tk-sort`） |
| 搜索/筛选控件 | 手写 `<input class="tk-search">`、6 个 `label+input` 复选框、2 个裸数字框 | `GWUI.input` / `GWUI.check` / `GWUI.select`（**id 全部保留**，事件绑定未动） |
| 工具按钮 | `<button class="tk-btn">`（无按下态、无焦点环） | `GWUI.btn`（凸起/悬停/按下下沉/焦点环/禁用态） |
| 提示 | 原生 `title`（不可换行、样式不可控） | `GWUI.tooltip`（换行、限宽 320px、视口翻转、`aria-describedby`） |
| 弹窗 | 本页没有 | 新增「数据说明」`GWUI.dialog`：把当前模式的真实数据事实（任务数/目标数/前置边/赛季专属/Kappa/阵营/攻略状态/生成时间/子集关系）摊开给用户看 |
| CSS 归属 | `tasks.css` 里 12 条规则管表格外观 | 这 12 条已删除；外观归 `ui-table`。`tasks.css` 只留布局与 `--ui-*` 引用的少量规则 |

`tasks.css`：223 → 215 条规则（删掉旧表格视觉，新增 2 条布局规则）。

## 四、遗留问题（如实记录）

1. **同模块其它页尚未迁移**：任务树、详情、进度页仍在用 `.tk-btn` / `.tk-alert` / `.tk-card` 等旧类。
   颜色一致（都取自 `--xp-*`），但按钮的按下态、焦点环、禁用语义与商人页不同。→ 下一批迁移对象。
2. **旧弹窗三套并存**：弹药 `.am-modal`、枪械配置 `.gw-prof-modal`、校准器 `.cal-modal` 仍是各自实现，
   `z-index` 分别是 90 / 9000 / 9990。`ui-dialog` 已可用，但迁移要逐个验证（尤其弹药详情弹窗有图表交互）。
3. **`title` 与 tooltip 的边界**：R19.22 约定用 `title` 承载英文原名（`data-en-text`），
   本轮只在"需要换行/富文本"的两处改成 `ui-tooltip` 并移除了 `title`。全项目仍有大量 `title`
   属于合理用法（简短英文名），不打算全部替换。
4. **表格列宽仍是字符串模板**：`colTemplate` 由调用方给出（如 `"minmax(140px,2fr) 84px 44px…"`），
   没有做成"列定义自动推导"。理由是各模块列宽差异大、且要与既有截图对齐；后续可加 `width` 汇总。
5. **未做暗色模式**：令牌已语义化，将来加暗色只需重定义 `--ui-color-*`，但本轮没有实现，也没有验证。
6. **未做移动端/窄屏重排**：1280 是最低支持宽度；更窄时允许横向滚动（未验证 1024 以下）。
7. **高 DPI 未实测**：未在 125%/150% 缩放下看过半像素与 1px 边框的渲染。
8. **地图画布未纳入**：画布内部的深色底、9–10px 标注、脚本注入的 SVG 样式保持原样（规范 §2.5 例外）。

## 五、后续迁移建议（只作建议，未执行）

按"风险低 → 高、收益大 → 小"排序：

| 顺序 | 模块 | 主要工作 | 风险 | 收益 |
|---|---|---|---|---|
| 1 | 任务树 / 详情 / 进度页 | `.tk-btn` → `ui-btn`；`.tk-alert` → `ui-panel`/`ui-badge`；筛选条已迁移，剩侧栏 | 低（验收已覆盖 58 项） | 同一模块内视觉彻底一致 |
| 2 | 弹药页表格 + 弹药详情弹窗 | 表格换 `ui-table`；弹窗换 `ui-dialog`（注意内部图表尺寸重算） | 中（图表依赖容器尺寸） | 去掉 90/9990 两个异常层级 |
| 3 | 配枪工作台 | 顶栏控件、候选列表、`.gw-tip` → `ui-tooltip` | 中（拖拽与搜索交互多） | 统一提示框实现 |
| 4 | 配装工作台 | 顶栏、价格档位、`fieldset` 分组框 → `ui-panel--group` | 高（页面最复杂，槽位板是定制可视化） | 最大的一块视觉债 |
| 5 | 校准器 | 浮层 → `ui-dialog`（宽版），按钮/输入换组件 | 中（拖拽坐标编辑） | 浮层实现统一 |
| 6 | 主题层收敛 | 删 `theme-windows-xp.css` 第 12/13/14 节（自动映射/修正/终层） | 高（改一处影响全站） | 彻底消除"三层覆盖" |

每步的验收动作固定：`pytest -q` 全量 + `tools/ui_accept.py` + 对应模块的浏览器验收脚本 + 前后截图对比。
