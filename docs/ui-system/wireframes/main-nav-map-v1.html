01三层信息架构

判断规则：用户在当前工作区会不会频繁用它？会 → 第 2 层；配置一次就不碰 → 第 3 层。

第 1 层 · 主导航 我现在在哪个工作区
地图 任务 配装 配枪 弹药 市场 常显 · 切换成本最低 · 不藏进菜单
第 2 层 · 页面工具栏 我现在能对这个工作区做什么
地图选择 图层搜索 楼层 定位 复位 只放当前页面相关操作 · 随工作区切换
第 3 层 · 应用菜单 我想调整应用怎么工作
保存配置 重新载入 小地图设置 自动截图 价格识别 数据源 关于 退出 收进一个「应用菜单 ▾」· 低频

现状是「文件 / 视图 / 帮助 / 小地图 / 价格识别 / 设置」六个一级菜单与工作区按钮并排， 视觉上像同等重要。改后顶栏只剩两层：主工作区 + 当前页工具栏。

05归属迁移表

第一阶段只做这张表里的「位置变化」，不改功能本身。

现在的位置改后的位置原因
顶栏「文件 / 帮助 / 小地图 / 价格识别 / 设置」五个一级菜单 一个「应用菜单 ▾」 低频配置不该与工作区并排；减少一级入口数量。
顶栏「视图」菜单（地图 / 任务 / 弹药 / 配枪 / 配装 / 市场） 直接作为主工作区按钮常显 同一件事不应该有菜单和按钮两个入口。
第三行上下文栏（地图选择等） 并入地图页工具栏 顶栏从三行降到两行，地图多出 34px 高度。
左侧栏「显示」三条滑条（地名 / 透明 / 图标） 地图页工具栏的「显示 ▾」弹层 调一次就很少动，不占侧栏高度。
右侧任务栏（搜索 / 四个勾选 / 任务列表） 检查器 · 任务标签页 任务列表只是「没有选中内容时」的默认态，不是永久并列。
地图 HUD（跟随 / + / − / 复位） 画布右下角紧凑工具条 不遮挡地图中心；与地图页工具栏职责分开。

06第一阶段范围

先验证「地图更突出、常用操作更快找到」，不碰业务逻辑。

  • 做：顶栏两层化与菜单归属调整（DOM 迁移为主，id / 事件沿用）。
  • 做：地图页工具栏承接地图选择、楼层、定位、复位、显示弹层。
  • 做：左右面板独立收起；右栏先保留现有任务列表，后续再切检查器标签。
  • 做：HUD 移到右下角，保持四个动作不变。
  • 不做：不重做 XP 皮肤、不改配色令牌、不引入新框架。
  • 不做：不动任务 / 配装 / 配枪 / 弹药页的内部结构（只跟随顶栏变化）。
  • 不做：不改配置键、不改数据文件、不改小地图与齿轮菜单。
  • 不做：不在第一阶段做标签分级算法，只预留 CSS / 状态位。

验收看三件事：顶栏是否只剩两层、地图可视面积是否变大、常用操作是否仍在一屏内找到。 三项都成立，再进入视觉收敛与检查器改造。
