# R18 · 全站 Windows XP Luna 换肤说明

本轮只改视觉：新增独立主题层 `theme-windows-xp.css`，在 `style.css` 之后加载。
**业务 JavaScript、计算公式、数据文件、交互逻辑一行未动**（`combat_sim.js` 完全未改，
`app.js` 只改了构建标记字符串 `AM_BUILD`）。

- 构建标记：`R18`（`app.js` 内的 `AM_BUILD`，模拟器顶部执行条可见）
- 资源版本：`index.html` 里 `style.css?v=r18`、`theme-windows-xp.css?v=r18`、
  `combat_sim.js?v=r18`、`app.js?v=r18`（同一轮统一升版，避免旧缓存）

## 一、实现方式（为什么这样做）

项目本身已经有一半是 Luna 浅色框架（菜单栏、地图侧栏、通用表格），但三个数据工作台
（配装 / 配枪 / 弹药 + 逐发模拟）是深色主题，且色值大量硬编码在 `style.css` 里。

主题层分四段，按顺序覆盖：

| 段 | 内容 | 作用 |
|---|---|---|
| 1 | `:root` 令牌（`--xp-luna-*` / `--xp-btn-*` / `--xp-row-*` …） | 统一颜色、边框、按钮渐变 |
| 2 | 三个工作台的**色板翻转**（`--lw-*` / `--am-*`） | 深色变量整体换成 Luna 浅色，尺寸变量一律不动 |
| 3 | 自动映射块（201 条 `html <原选择器>` 规则） | 把 `style.css` 里配装/配枪/弹药/模拟器作用域的**硬编码深色值**逐条翻成浅色（仅颜色声明，不含布局） |
| 4 | 手写组件层 + 终层 | 按钮三维凸起、输入框凹陷、标签页、表格、弹窗蓝标题栏、滚动条、提示气泡；终层把被自动块盖掉的渐变面重新压回 |

自动映射脚本只处理 `background / color / border*` 三类声明，且只在该四个作用域内生成规则，
**不产生任何布局声明**（有测试断言：无 `grid-template`、无新增 `position: fixed`）。

## 四、已知差异与剩余问题

1. **地图画布仍是深色**：底图与彩色标注压在上面，浅底会看不清；这是既有设计，
   本轮只把 HUD / 状态条 / 浮窗换成 XP 外观。若要求画布也浅色，需要单独调底图配色。
2. **配装左侧卡片板的图标是灰阶剪影**（本地资源本身如此），换浅底后对比度比深底略低，
   但没有信息缺失；未替换素材。
3. **表格密度沿用原样**：XP 经典列表行的行高比现在略大，但配装表是按参考图逐像素校准的，
   本轮**没有改行高/列宽**，避免破坏既有 20 列排版。
4. **滚动条只在 Chromium 下是 XP 样式**（`::-webkit-scrollbar`）；Firefox 沿用
   `scrollbar-color`（原样式保留），观感略不同。
5. **无头截图存在合成器旧帧问题**：某些滚动容器/浮层截图可能显示上一帧配色。
   验收结论以 DOM 计算样式 + 像素统计为准（本次对模拟器日志区、配装表、详情弹窗都做了
   像素采样：深色像素占比 < 1.5%）。
6. **没有做系统原生窗口装饰**（最小化/最大化/关闭）：按任务要求不伪造无功能按钮。
