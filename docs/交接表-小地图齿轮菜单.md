## 1. 一句话现状

小地图窗口加载的是**同一个 `index.html`**（`index.html?mini=1`），只是 `body` 多一个 `tk-mini` class 把 `#menubar / #sidebar / #task-panel` 全部隐藏（`style.css:8139-8147`）。所以：

- 「一级选单里的小地图设置」面板 `#am-mini-panel` **本来就在小地图文档里**，只是随 `#menubar` 一起被隐藏 → 用户说「游戏里调不了」成立；
- 左右图层选单也在同一文档里，同样被隐藏；
- 因此三个子菜单**不需要新写逻辑**，只需把已有节点在菜单打开时挪进菜单容器。

## 4. 三条实现路线（含推荐）

### 路线 A：DOM 迁移（**推荐**）

菜单打开时，用 `Node.appendChild` 把三个已有块**移动**进菜单页签；关闭时移回原父节点并记录 `nextSibling` 以便原位还原。

- 优点：零逻辑复制，`id` 不变 → 现有 `addEventListener` 全部继续有效；改一处即两处生效。
- 缺点：需要处理「原位还原」与父级样式（`#sidebar`、`#task-panel` 的 CSS 上下文变了）。
- 落地要点：
  ```js
  var slots = [
    { el: $("#am-mini-panel"), parent: null, next: null },   // 子菜单 1
    { el: $("#layers-block"),  parent: null, next: null },   // 子菜单 2（配合 #floor-block、#wiki-panel）
    { el: $("#task-layer-toggles"), parent: null, next: null } // 子菜单 3
  ];
  function mount(entry, host) {
    entry.parent = entry.el.parentNode;
    entry.next = entry.el.nextSibling;
    host.appendChild(entry.el);
  }
  function unmount(entry) {
    if (!entry.parent) return;
    entry.parent.insertBefore(entry.el, entry.next);
    entry.parent = entry.next = null;
  }
  ```
- 注意：`#layers-block` 等是 `<section class="block">`，迁移后要补 `classList.add("tk-mini-menu-scope")`，把 `.block` 的边距/宽度在当前容器下重设。

### 路线 B：镜像 UI（只读复制 + 调 setter）

在菜单里重建一份精简列表，读写都走 `state` + 显式 setter（需要先把图层开关抽成 `setLayer(key,on)` 这类函数）。

- 优点：样式自由、窄窗排版最容易做对；不受父级 CSS 影响。
- 缺点：要为「图层 / 楼层 / 官方图层 / 任务图层」各写一份镜像与同步（约 +1.5 人日），且两份 UI 容易走偏。
- 适用：路线 A 在 120px 尺寸下排版不可行时的降级方案。

### 路线 C：命中测试（若 P0 证明「关穿透」不可行）

不关闭 `WS_EX_TRANSPARENT`，改为宿主处理 `WM_NCHITTEST`/`WM_MOUSEMOVE`：只有鼠标落在齿轮矩形的物理坐标内时才临时 `SetClickThrough(false)`。

- 优点：平时保持穿透，不抢游戏鼠标。
- 缺点：要处理窗口缩放/多屏 DPI（`plan_rect` 已算物理坐标，可复用）；实现复杂度最高。
- **先做 P0 验证，只有 A 方案的「开菜单时整体关穿透」不可接受时才走这里。**

## 5. 三个子菜单落地要点

### 子菜单 1 · 小地图（等价 `#am-mini-panel`）

- 节点：`#am-mini-panel`（整块 `.app-menu-panel`，含 `display:none` 逻辑由宿主菜单控制）
- 迁移时必须**去掉 `hidden` 并覆盖 `.app-menu-panel` 的绝对定位**（它原先是相对 `.app-menu` 定位的弹层）
- 内部依赖：`el.ovEnabled/ovSize/ovOpacity/ovCorner/ovOffsetX/ovOffsetY/ovShape/ovLabels/ovFollow/ovClick`、`el.miniRadius/miniLabelScale/miniLabelAlpha/miniIconScale`、`el.miniShot/miniShotInterval/miniShotsDir/miniLogDir/miniShotCleanup/miniShotKey/miniPathsNote`
- 写入：`queuePrefs({ overlay: {...} })` 与 `queuePrefs({ auto_screenshot: {...} })`，与主界面完全同一份配置
- 注意：`applyAutoShotSettings()` 对非会员把间隔输入框 `disabled`（`app.js:7397`），迁移后不要绕过

### 子菜单 2 · 左栏图层（等价 `#sidebar` 的图层区）

- 迁移 `#layers-block` + `#floor-block` + `#wiki-panel`，**不要**迁 `#sidebar` 里的任务/设置等无关块
- 渲染仍是 `renderLayerToggles()`（`app.js:2313`）；它按「当前地图计数为 0 则整行隐藏」的规则跑，小窗与大窗共享同一 `state.layers`，迁移不改变该逻辑
- `#floor-block` 有 `hidden` 属性（无楼层图时隐藏），迁移后保持读取同一属性即可
- `#wiki-panel` 的分类由 `wiki-map.js` 渲染并自行管理折叠，不要重复绑定

### 子菜单 3 · 右栏任务图层（等价 `#task-layer-toggles`）

- 只有 4 个勾选（任务 × 完成/未完成、剧情 × 完成/未完成），状态在 `state.taskLayerFilters`，落盘 key `eftmap.taskLayerFilters.v1`
- 折叠状态在 `state.taskLayerFold` / `LS_TASK_LAYER_FOLD`，与勾选值互不影响（原有设计，勿合并）

### 菜单交互

- 齿轮：内联 SVG（无现成素材，`assets/icons/` 里没有 gear），28×28 触控目标，右上角 `top:6px; right:6px`，圆形裁剪下需确保在圆内
- 开合：点齿轮切换；点菜单外/Esc 收起；**切图或收到 `map` 事件时强制收起**（避免菜单浮在另一张图上）
- 开合必须成对调用穿透开关，否则会出现「关不掉穿透导致游戏鼠标被吃」或「菜单点不动」

## 6. 已知坑（逐条给规避）

| 坑 | 现象 | 规避 |
| --- | --- | --- |
| 穿透 | 齿轮完全点不到 | 菜单打开必须 `SetClickThrough(false)`；参照 `EnterFull()`（`MiniHost.cs:875`） |
| 穿透未恢复 | 关菜单后游戏点不动 | 在 `mouseleave` / `Esc` / 切图 / 窗口失焦四处都调用恢复；恢复要幂等 |
| `.app-menu-panel` 定位 | 迁移后菜单飞到屏幕外 | 迁入容器后加作用域类，`position:static/absolute` 由新容器决定，并覆盖 `min-width` |
| 父级样式丢失 | `.block` 无内边距、分割线消失 | 作用域类里补齐 `.block` 关键样式（`padding` / `border-top` / `h2` 字号） |
| 回声抖动 | 拖滑条时数值来回跳 | 沿用 `ovReady` 守卫（`app.js:7332`）；只在 `value` 真变化时写 |
| `renderLayerToggles` 重入 | 迁移后每次切图重建 DOM，导致节点被我方引用失效 | **不要缓存节点引用**，每次打开菜单重新查询；或监听重建后重新挂载 |
| 120px 窗口 | 菜单放不下 | 宽度 <200px 时降级：只显示「视野 + 图层总开关」，其余提示去大窗调 |
| 圆形裁剪 | 菜单被裁成半圆 | 菜单容器挂到 `body` 而不是 `#stage`，并 `body.tk-mini[data-mini-shape="circle"]` 下不受 `overflow` 影响 |
| XP 主题 | 配色不跟随 | 只用 CSS 变量（`--lw-panel-*` 系列），不写死 `#fff` |
| 全图模式 | `EnterFull` 已经关穿透，退出时又恢复成 `_cfg.ClickThrough` | 菜单状态与 `_full` 互斥判断：`_full` 时不要重复恢复穿透 |
| 版本号 | 忘记同步 | `tools/serve.py` 与 `tools/installer.py` 的 `VERSION` 必须同时改（有测试锁死） |
