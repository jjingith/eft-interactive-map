## 2. 范围

**做**

1. `index.html` 偏移 X 滑条范围 → ±300（Y 是否同步由用户决定，默认**不动**）。
2. 小地图窗口内新增：齿轮按钮（内联 SVG，无新素材依赖）、菜单容器、3 个页签。
3. 菜单打开时关闭窗口点击穿透、关闭时恢复（复用宿主已有范式）。
4. 三个子菜单与现有面板**共用同一份 DOM 与同一批事件绑定**（不复制逻辑）。
5. 新增自动化测试：偏移范围、齿轮按钮存在性、菜单开关与穿透状态、子菜单内容锚点。

**不做**

- 不改主界面布局 / 主界面菜单行为（主界面必须零变化）。
- 不新增后端接口（现有 `POST /api/prefs` + SSE `config` 已够）。
- 不改 `tools/overlay.py` 的窗口定位算法（只改取值范围）。
- 不做主题重绘（沿用现有 `.app-menu-panel` / `.tk-mini` 变量）。

## 5. 风险登记

| 风险 | 影响 | 概率 | 应对 |
| --- | --- | --- | --- |
| 穿透窗口里按钮点不到 | B 无法实现 | 高（默认 `click_through=true`） | P0 先验证；优先「开菜单时整体关穿透」，退化方案见交接表 §4 路线 C |
| 关闭穿透后游戏鼠标被窗口吃掉 | 影响玩法 | 中 | 只在菜单打开期间关穿透，并在关闭/失焦/切图时强制恢复 |
| DOM 迁移导致样式崩 | 菜单丑/不可用 | 中 | 迁移时给容器加 `class="tk-mini-menu-scope"`，把需要的 `.block` 样式作用域化；先做子菜单 1 验证 |
| 小窗自写 prefs 收到 SSE 回声来回抖动 | 控件跳动 | 中 | 沿用 `ovReady` 守卫（7332）+ 只在值变化时写 |
| XP 主题覆盖 | 菜单配色错乱 | 中 | 复用 `theme-windows-xp.css` 已有的 `.app-menu-panel` 变量，禁止硬编码颜色 |
| 会员门控项在菜单里被绕过 | 权益漏洞 | 低 | 子菜单 1 的自动截图间隔等沿用 `isMember()` 判定，不新增旁路 |
| 窄窗放不下 | 无法操作 | 中 | 页签 + 滚动 + 折叠分组；120px 尺寸下降级为「只显示视野与图层总开关」 |
